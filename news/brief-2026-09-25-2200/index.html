业内新闻

  • MIT 出来的 agent 推理公司，9/22 宣布融资 510 万美元。
  • 这期是补收，因为它直接撞上你研究的上下文压缩方向。
  • 卖点是动态上下文压缩 + 高效缓存。
  • 动态上下文压缩说白了：agent 跑任务时，用不着的历史对话先压小。
  • 压小了 token 就省，等于少烧算力、省钱。
  • 高效缓存就是 KV cache：算过的草稿纸留着，省得重算。
  • 官方自称：长 agent 任务能省 80% 的 token。
  • 20 万 token 以上的长任务，速度快一倍。
  • 还称在 TriE 基准上比 SGLang 快一倍。
  • 划重点：以上数字全是厂商自报，没人独立验证过。
  • 当八卦看可以，别当实测数据用。
  • 值得你看的原因：它是专为长 agent 会话做的 serving 层。
  • 正好撞上前缀缓存（prefix caching）和上下文压缩的前沿。
  • 也算 SGLang 和 vLLM 的新对手。
