头条

FluidPD：PD 解耦里，两拨人手不够就原地换角 IBM Research 的新论文。 PD 解耦下读题/吐字需求比忽上忽下，固定配比一错配就违约。 SLO 是服务等级目标，这里指延迟达标线。 这篇给两个旋钮：瞬时把读题计算卸给有余量的吐字 worker。 持续不平衡就让 worker 原地换角色，不重启、不重载模型。 压力指数 PPI/DPI 在违约前先报警。 正好是你 autotuner 缺的提前量信号。 Azure trace 上回放。 SLO 达成率最高提升 94.6 个百分点。 6 卡 FluidPD 打赢 8 卡的 Dynamo 自动扩缩。 数字全是作者自报。 SLO 口径是 3000ms 首字、150ms 吐字。 这篇已做深读笔记，见文末。 来源：https://arxiv.org/abs/2610.06917

新技术与论文

arXiv 10/31 批次终于发布 之前两轮亲查都没出，这轮约 09:00 UTC 可见。 cs.CL 一天 108 篇。 推理 serving 相关的扫出 27 篇新的。 下面按主题挑重点，其余速览，全部作者自报、仅供参考。

推测解码专场：草稿长度、能耗账、训练纠偏 TableTune：实测 vLLM 每种 batch 下的最优草稿长度。 几分钟算出一张表，在线跟踪接受率自我修正。 手写 draft-length 表的可以直接换。 vLLM 插件形式，开箱即用。 来源：https://arxiv.org/abs/2610.38968

Only Accepted Tokens Count：推测解码的能耗账本。 被拒的草稿 token 全是白耗电，这篇在延迟目标下算清每笔账。 数据中心按每 token 能耗算账时会用上。 来源：https://arxiv.org/abs/2610.40287

Multi-Token Prediction Done Right：标准多词元预测训练有毛病。 残差梯度同时干扰下词元和多词元学习，规模越大越重。 分解出 KL 自蒸馏项后，下游涨、推测解码也利好。 来源：https://arxiv.org/abs/2610.38331

Speculative Acceptance Does Not Decay with Position：打脸行业叙事。 之前都说接受率随 CoT 变长衰减，这篇全长度实测说纯位置效应不存在。 之前的证据用的草稿器训练长度太短，量错了尺子。 来源：https://arxiv.org/abs/2610.30644

其余速览： T2D（2610.34103）：把草稿模型构建写成剪枝加适配的优化问题。 RCSD（2610.29527）：用 RL 直接对齐接受率，不硬拟合 target 分布。 ValuSpec（2610.31338）：树形推测解码先给候选分支打分再验证。 Understanding Target Probability Reuse（2610.29210）：验证时顺手拿到的分布能不能复用。

KV 缓存与量化：压缩、量化、对齐 RAQ-MLA：专为 MLA 缓存设计的量化。 MLA 的 latent 和窄位置 key，跟标准 K/V 不一样。 得按角色区别对待。 你关心 MLA 精度，这篇值得翻。 来源：https://arxiv.org/abs/2610.33625

ZipFusion：attention 直接吃压缩态的 KV。 以前无损压缩要先解压回显存再算，这篇省掉重复读和解压。 来源：https://arxiv.org/abs/2610.33719

FAD-KV：用自适应字典把 KV 表成稀疏基组合。 面向长输出推理的 KV 压缩。 来源：https://arxiv.org/abs/2610.37921

其余速览： KV Cache Quantization for Diffusion LMs（2610.39853）：扩散语言模型的 KV 量化。 DeferKV（2610.06286）：一次性 KV 压缩别急着驱逐，等 decode 初期的真实信号。 AlignQuant（2610.07457）：混合精度量化的精度边界跟 GPU 单元对齐。

部署与扩缩：serverless、K8s、模拟器 GearUp：serverless 推理是函数 DAG。 按关键路径的 slack 做预加载。 省掉权重和 kernel 的加载等待。 来源：https://arxiv.org/abs/2610.38196

InferScale：K8s 原生预测式扩缩。 推理感知信号加短期需求预测，不替换默认调度器。 来源：https://arxiv.org/abs/2610.34006

Simulate Before You Scale：上 GPU 集群试参太贵。 高保真模拟器做硬件布局和调度选型，不用真卡。 来源：https://arxiv.org/abs/2610.14255

Evaluating Inference Compute（2610.07094）：agent 时代 batch=1。 吐字间隔成了主导成本。 用 roofline 加闭式延迟模型论证该选什么加速器。

其他速览 CopyLoop（2610.38822）：循环 Transformer 免训练加速，上下文拷贝加浅层筛查。 GPU-Resident Speculative Decoding（2610.39761）：浏览器里整套推测解码做成 GPU 常驻循环。 SPECMEM（2610.31840）：agent 工具调用的记忆库做草稿源。 Speculative Diffusion is a Tale of Two Tradeoffs（2610.31819）：扩散 LLM 的加速是拿质量换的。 Cord（2610.39372）：masked 扩散 LM 先揭哪块的顺序策略。 Multi-Draft On-Policy Distillation（2610.37778）：扩散草稿器的多草稿在线蒸馏。 One Call Ahead（2610.33379）：一次前向同时完成草稿与验证。 RIPE（2610.34436）：循环 LM 里深层对前缀 KV 扰动更敏感，按层定缓存。
