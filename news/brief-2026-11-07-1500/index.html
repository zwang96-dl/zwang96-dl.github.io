15点版来了。

这轮框架合入不少。 vLLM 删了老跑法。 SGLang 补了三个漏报的安全修复。 论文新一批还没出。

框架更新

版本水位：只动了一个快照

llama.cpp 每日快照从 b12189 涨到 b12192。 b12191 和 b12192 都在窗口里出的。 每日快照就是每天自动打的构建号。 不算正式发版。 其余全平：vLLM v0.33.0，SGLang v0.5.23。 TRT-LLM v1.4.0rc3，LMDeploy v0.18.0。 TGI v3.3.7，Dynamo v1.6.2。 FlashInfer 还是 v0.7.4rc1。 正式版还是 v0.7.3。 Mooncake v0.3.14。 来源：GitHub releases

vLLM：3 条，删老跑法那条最值得记

vLLM 合入 #63373。 删掉了 Model Runner V1。 Model Runner 就是真正跑模型的那层。 V2 早就是默认了。 老版只剩一个环境变量能开。 这次连同只为它存在的代码一起删了。 Dual Batch Overlap 以后默认跑在 V2 上。 Dual Batch Overlap 是让两批请求重叠算的优化。 以后升级不用再惦记老跑法了。 来源：https://github.com/vllm-project/vllm/pull/63373

vLLM 还合入 #66000。 修的是 Step5 的 MTP 投机解码。 Step5 是英伟达的新模型。 流水线并行大于 1 时，启动会报错。 现在跳过重复的配置校验。 还保住了目标模型的 CUDA 图设置。 CUDA 图就是把整段计算预先录好。 来源：https://github.com/vllm-project/vllm/pull/66000

其余一条是小活。

#63166 修 ROCm 上的一处测试失败。

test_qwen.py 在 AITER 开启时报错。 AITER 是 AMD 的内核库。

SGLang：5 条，缓存上报那条最相关

SGLang 合入 #49030。 rust-server 开始上报缓存命中的 token 数。 开 --enable-cache-report 就能看到。 OpenAI 路由会直接报缓存了多少 token。 rust-server 是 SGLang 的 Rust 重写版服务端。 上轮刚合入 JSON 日志，这次是同一套组合拳。 以后看前缀缓存命中率，不用再自己翻日志算了。 跟你的前缀缓存评估直接相关。 来源：https://github.com/sgl-project/sglang/pull/49030

SGLang 还合入 #49001。 MI450 的自定义 all-reduce 调优。 MI450 是 AMD 下一代卡。 all-reduce 是多卡之间同步数据的操作。 旧的调优表在 MI450 上比 RCCL 慢 21%。 这次换了 MI450 专用的表。 你的 MI350X 不受影响，但能看出 AMD 在给新卡铺路。 来源：https://github.com/sgl-project/sglang/pull/49001

其余三条都是小修补。

#47862 给每个模型配一份内置的 aiter 调优参数。

#49092 修 kv-canary 的 warmup 传参。

#49093 修 ernie55 的导入路径。

kv-canary 是 SGLang 里探 KV 缓存状态的小工具。 warmup 就是正式开跑前的热身。

FlashInfer：5 条，全是 cake 内核打磨

FlashInfer 合入 #9120。 gated_act 的 MXFP8 内核换了新程序。 小调用更快，覆盖 SM100 和 SM107。 SM100 是 Blackwell 那代卡。 SM107 是 Rubin 那代卡。 FlashInfer 还合入 #9114。 NVFP4 的 MLA 分页解码宽路由瘦身了。 MLA 是 DeepSeek 那种省显存的注意力。 NVFP4 是一种 4 位浮点量化。 FlashInfer 还合入 #9116。 GQA 的 split backward 更快了。 结果逐位一致。 GQA 是分组查询注意力。 其余两条也是 cake 打磨。

#9118 给 GDN 反向的伴随表计价。

#9106 给因果卷积反向加更多 32 向量块。

正向也加了 BF16 抽头。 来源：https://github.com/flashinfer-ai/flashinfer/pull/9114

llama.cpp：1 条，多模态音频的小修补

llama.cpp 合入 #31808。 mtmd 把 log-mel 计算挪进计算图。 mtmd 是 llama.cpp 里处理多模态的那块。 log-mel 是音频转特征的第一步。 以前音频预处理自己开线程。 请求一多，线程数会爆炸。 现在挪进计算图，统一调度。 还修了 Metal 上 DFT 的偏差。 DFT 是傅里叶变换。 来源：https://github.com/ggml-org/llama.cpp/pull/31808

补报：SGLang 三个安全修复，之前几轮漏了

之前几轮漏了这三条，这轮补上。 SGLang 合入 #48518。 /server_info 接口会泄露管理密钥。 拿普通密钥的人也能看到 admin_api_key。 现在打码了。 日志、启动命令、崩溃转储里也一起打码。 跑 SGLang 的话，值得升一下。 来源：https://github.com/sgl-project/sglang/pull/48518

SGLang 还合入 #48512。 rust-server 收了 --api-key 却不校验。 等于门上挂了锁却没锁上。 这次开始真正强制校验。 忽略的 flag 直接拒绝。 warmup 失败就退出。 来源：https://github.com/sgl-project/sglang/pull/48512

SGLang 还合入 #48446。 批量请求共用同一份采样参数。 一个请求的截断会连累邻居。 现在每人一份，各改各的。 来源：https://github.com/sgl-project/sglang/pull/48446
