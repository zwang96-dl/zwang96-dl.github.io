STEPQuant：循环状态的量化，得看误差"住多久、住哪格"

原文：https://arxiv.org/abs/2609.38169 代码：https://github.com/Dreamer-Toby/STEPQuant 作者：Bingchen Yao、Haobo Xu（共同一作）、Haokun Lin 等 单位：浙江大学、中科院自动化所、清华、港城大、哈佛、港中文 日期：2026-09-30

人话解读

线性注意力把历史压成一块固定大小的"循环状态"。 线性注意力是一种 KV 不随长度涨的注意力变体。 状态大小不随长度涨，但并发请求一多，显存照样吃紧。 直接把这块状态量化成低精度，模型精度崩得厉害。 因为量化误差会跟着状态更新一轮一轮传下去，越传越大。 这篇论文发现了两个规律：误差"住多久"和"住哪格"，决定了它伤不伤精度。 解法就叫 STEPQuant：按寿命和位置，给不同的格子配不同的精度。

一句话：量化循环状态不能一刀切，得看每块记忆的"寿命"和"住址"。

核心方法

STEPQuant 是时空双维量化。 英文全称 Spatial-TEmporal Quantization。

第一招：时间维，寿命感知的精度分配。

  • 状态单元：Qwen 里是整个 head。
  • Kimi-Linear 里是 key 的一行。
  • 门控（gate，控制记忆忘多快的开关）留得越久，误差传得越久。
  • 实测：门控半衰期越长的 head，均匀 INT6 量化下累积误差越大。
  • 目标：在固定总 bit 预算下，最小化"按寿命加权"的重建误差。
  • 做法：寿命长的单元分高精度，寿命短的分低精度。
  • 极少数实在难量化的高风险单元，直接留 FP16。
  • 这叫"钉子户"（sparse pivots）。
  • 类比：酒店按住多久定装修。常住客住套房，过客住标间，总预算不变。

第二招：空间维，按 key 行影响的双轴拟合。

  • 同样大小的误差，落在不同的 key 行，对输出的伤害天差地别。
  • 状态数值在行、列两个方向都很不均匀，还有顽固的离群通道。
  • 离群通道在整个 decode 过程中一直都在，不是昙花一现。
  • 解法：key 行和 value 列各配一套 scale（双轴）。
  • 行 scale 同时看该行数值大小，和它对输出的实测影响。
  • 列 scale 在"误差更要命"的行上加更大权重。
  • 类比：重要的格子用细笔写，不重要的用粗笔，纸面利用率最高。

两招都只在离线校准时定好，线上请求来了直接用，不加推理开销。

关键数据

两个模型：Qwen3.8-27B、Kimi-Linear-48B-A3B。7 个长生成 + 6 个短生成任务。

  • 6-bit：两模型精度基本追平 FP32 状态。
  • 4-bit：两模型都超过均匀 INT8。Qwen 上接近 FP32。
  • 接入 SGLang 加优化 kernel。
  • 循环状态内存压 5.03×（Qwen）/ 5.08×（Kimi）。
  • 总 serving 内存降 68.7%（Qwen）/ 53.7%（Kimi）。
  • 含模型权重。
  • batch 512 时：状态内存 −80.1%，状态更新时间 −65.6%。
  • 状态更新本身快 2.91×。
  • 消融（4-bit，Qwen）：完整版 84.72%。
  • 只用空间维 73.95%，只用时间维 12.87%。
  • 对照 Q-Mamba 的 DSQ 方法：4-bit 下它只有 7.64%。
  • STEPQuant 是 84.72%，差距巨大。

跟你研究方向的关联

  • 量化线的新维度：以前盯的是权重和 KV 缓存。
  • 这篇盯的是线性/混合模型的循环状态。
  • SGLang 已经有实现 + 优化过的 GPU kernel。你评估 SGLang 时可以直接拿来试，不用自己造轮子。
  • P/D 解耦评估：decode 侧内存规划可以借鉴这套思路。
  • "按寿命配精度"：长寿的状态多给 bit。
  • AI 自动调参系统：bit 分配策略是现成的可调参数。
  • 寿命加权是个好目标函数。
  • 局限：只测了 delta 规则的线性注意力模型。
  • Qwen3.8、Kimi-Linear 这两个。
  • 标准 Transformer 的 KV 缓存不直接适用。

术语表

  • 线性注意力：KV 不随长度涨的注意力变体。
  • 历史压成固定大小的状态矩阵。
  • Delta 规则：更新循环状态的规则。
  • 带门控，老记忆按比例保留。
  • 循环状态：线性注意力的固定大小"记忆本"。
  • decode 每步都更新它。
  • 门控半衰期：记忆"忘一半"要经过多少 token。越长，寿命越长。
  • KDA：Kimi-Linear 用的 delta 规则注意力实现，论文里的简称。
  • 双轴拟合：key 行和 value 列各配一套量化 scale。
  • Sparse pivots：极少数留在 FP16 的高风险单元。
  • AWQ：一种 4-bit 权重量化方法，论文里权重用的就是它。
