多模态大模型推理服务简报 · 2026-10-30（20点版）

20点版来了，这轮框架侧 30 笔常规合入。 头条是国产卡把 PD 又拆了一层。 三个 RC 版本都在路上，正式版还没动。 arXiv 零入库，DeepInfer 星标涨了 13 个。

头条

国产卡把 PD 又拆了一层 天数智芯的天垓300 出了新实测。 PD 分离部署下，单卡吞吐是 H200 的 1.05 倍。 他们还展示了 AFD 方案。 AFD 是在 PD 基础上，把 Decode 再拆。 注意力和前馈网络各跑各的。 Decode 延迟降了 60%。 先说清楚：这些全是厂商自报数据。 没有第三方验证，先看个方向。 跟你正在评估的 PD 解耦直接相关。 这条是窗口外补报，之前几期没报过。 来源：https://k.sina.cn/article_5953466437_162dab0450670bgh30.html?from=tech

框架更新

TRT-LLM：PD 配对的取消不再卡住 PD 解耦就是 prefill 和 decode 分工流水线。 CTX 和 GEN 是 PD 里的一对搭档。

#20491 修的是：一边挂了，另一边别傻等。

取消信号现在能传过去，健壮性加分。 来源：https://github.com/NVIDIA/TensorRT-LLM/pull/20491

TRT-LLM：KV 事件开始带图像路由信息

#21125 让 KV events 带上图像路由元数据。

多模态请求的 KV 流向终于能看见了。 多模态可观测性的小进步。 来源：https://github.com/NVIDIA/TensorRT-LLM/pull/21125

vLLM：NIXL 升到 1.5.2 NIXL 是 PD 搬运 KV 的高速通道。 这笔是纯版本升级，功能面没动。 来源：https://github.com/vllm-project/vllm/pull/64579

vLLM：Kimi-K3 的 prefill 存档留住了 prefill checkpoint 是 P 端算完先存档。

#63297 让 Kimi-K3 用 gluon 后端保留它。

AMD 卡上跑，PD 路径更顺。 来源：https://github.com/vllm-project/vllm/pull/63297

vLLM：gfx950 上 prefix-cache 支持 SWA replay prefix cache 是把算过的开头存起来复用。 SWA 是滑动窗口注意力，一种省显存的注意力。 DSv4.1 在 AMD gfx950 上能复用窗口了。 来源：https://github.com/vllm-project/vllm/pull/64094

FlashInfer：NVFP4 那版优化被回滚了

#8075 回滚了之前的 #8040。

那笔是 NVFP4 可变长注意力的性能优化。 回滚说明改动有问题，先撤回来。 量化 attention 这条路还在反复试。 来源：https://github.com/flashinfer-ai/flashinfer/pull/8075

SGLang：文生图两笔优化 Qwen-Image-2.1 的纯文本编码器。

#47467 让它走 CUDA graph 重放。

#47465 把 Q/K norm 加 RoPE 按半 warp 排。

多模态这边的文生图管线又快了一点。 来源：https://github.com/sgl-project/sglang/pull/47467 来源：https://github.com/sgl-project/sglang/pull/47465

SGLang：NPU 稀疏 offload 的缓存预算修了 DSA 是 DeepSeek 的稀疏注意力。

#45302 修正了它的 index-cache 预算。

NPU 上跑稀疏注意力更稳了。 来源：https://github.com/sgl-project/sglang/pull/45302

SGLang：Minimax-M3 的 decode 确定性修了

#45174 修了 radix decode 的 top-k 平局打破。

跟 18点版报的确定性账本是一类账。 来源：https://github.com/sgl-project/sglang/pull/45174

llama.cpp：SYCL 量化拷贝的精度修了 f32 转低比特量化时 rounding 有误。

#31120 把它修好，量化不丢精度。

来源：https://github.com/ggml-org/llama.cpp/pull/31120

业内新闻

Mac 出租 GPU 搞推理，已经不赚钱了 The Register 报道了 Darkbloom 的提醒。 分布式推理网的 token 价格 5 月以来跌了 54%。 Mac 挂机一天只赚几美分到几美元。 中位数一天约 5.26 美元。 分布式推理的经济账越来越难算。 来源：https://www.theregister.com/ai-and-ml/2026/10/30/darkbloom-which-allowed-mac-users-to-rent-out-their-gpus-for-ai-inference-warns-of-low-payouts/5306782

NVIDIA 边缘推理教程：DGX Spark 跑小模型 官方博客演示 DGX Spark 64GB。 用 TensorRT Edge-LLM 0.11.1。 跑的是 Nemotron-3.5-Lightning。 NVFP4 是一种 4 位浮点量化。 开 DSpark 推测解码后。 生成速度从约 73 tok/s 提到 105-127 tok/s。 首 token 延迟几乎没变。 数字是官方自报，仅供参考。 来源：https://blockchain.news/news/nvidia-edge-ai-dgx-spark-tensorrt-edge-llm-nemotron-3-5-lightning

Google Cloud：Agent 时代 CPU 戏份变多 Google Cloud 基础设施 VP 接受专访。 Agent 要调 API、跑代码，都是 CPU 的活。 CPU 在推理 workload 里占比明显上升。 最优的 CPU 和 GPU 配比还在演化。 信源是聚合站转述 EE Times 专访。 来源：https://www.indexbox.io/blog/agentic-ai-is-reshaping-data-center-cpus-says-google-clouds-mark-lohmeyer/

DigitalOcean 推理上新：GPT-6.1 Terra 官方发布记录 10/30 更新。 GPT-6.1 Terra 在 serverless 推理上可用。 o1、o3-mini 已于 10/26 退役。 用旧模型的记得迁到 GPT-5.6 Sol。 来源：https://docs.digitalocean.com/release-notes/inference/

Altman：本地跑模型是浪费内存 Sam Altman 在播客里说。 家用电脑的内存躺着是硅产能错配。 推理应该在云端集中跑。 PC 社区不太买账，评论区吵翻了。 这条时间在窗口边缘，信源是聚合站。 仅供参考。 来源：https://pivotnews.ai/five/local-ai-inference-is-a-bad-use-of-scarce-memory-altman
