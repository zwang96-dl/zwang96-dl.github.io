vLLM：5 条，工具调用解析器换引擎了

#62728 是工具调用的活。

Muse Spark 的解析器搬到流式解析引擎。

流式解析就是边吐字边认工具调用。

以前要等整段到齐才认。

#61690 是个小功能。

迭代指标里可选加 GPU 计时。

GPU 计时就是每步花了多少毫秒。

#68484 是结构化输出的简化。

token 位掩码的分配逻辑收敛了。

位掩码就是标记哪些 token 能出的表。

#68376 是修补。

修了 NemotronLabsDiffusion 的同步检查。

问题出在 GPU 同步上。

#68480 是 CI 的小调整。

来源：https://github.com/vllm-project/vllm/pull/62728

SGLang：21 条，Rust 服务端一口气补齐接口

这轮合入的 21 条里，18 条是 Rust 服务端。

Rust 服务端就是 SGLang 用 Rust 重写的服务层。

补的是各家 API 的路由和模型定义。

OpenAI 的对话和补全接口有了。

Anthropic 的 Messages 接口有了。

Ollama 的路由也有了。

还有打分、向量、重排、tokenize 这些接口。

说白了，Rust 版快能平替 Python 版了。

#50853 跟 P/D 解耦沾边。

/v1/loads 现在上报完整 decode 主机池。

还上报已落地的跨主机传输。

P/D 解耦就是读题和生成分开跑。

这接口方便调度器看清 decode 侧的负载。

#51038 是调度器修补。

DP 注意力下，空闲批次也上报负载了。

来源：https://github.com/sgl-project/sglang/pull/50853
