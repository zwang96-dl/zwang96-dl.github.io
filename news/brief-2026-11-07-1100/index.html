多模态大模型推理服务简报 · 2026-11-07（11点版）

11点版来了。

这轮比 09点版热闹一点。 Qwen 4 还是没来。 但隔壁 Qoder 先悄悄上了一个神秘模型。 框架那边合入不多。 多模态相关的有两条。

框架更新

版本水位：全平，一个没动

vLLM 还是 v0.33.0。 SGLang 还是 v0.5.23。 TRT-LLM 还是 v1.4.0rc3。 LMDeploy 还是 v0.18.0。 TGI 还是 v3.3.7。 Dynamo 还是 v1.6.2。 FlashInfer 还是 v0.7.4rc1。 正式版还是 v0.7.3。 llama.cpp 还是 b12189。 没有新快照。 来源：GitHub releases

SGLang：1 条，多模态小修补

SGLang 合入 #49006。 rust-server 把图片细节提示传给多模态处理器。 rust-server 是 SGLang 的 Rust 重写版服务端。 这条是那条长链路上的最后一环。 改动很小，先记一笔。 来源：https://github.com/sgl-project/sglang/pull/49006

Dynamo：1 条，多模态 worker 的修补

Dynamo 合入 #18053。 修的是 SGLang 的多模态 worker。 开思考加强制工具调用时，前后端会抢边界。 原因是推理门控的信息没公示。 现在按 worker 角色公示门控。 两边不再打架。 H100 上拿 Qwen3.5-4B 实测，6 个场景全过。 来源：https://github.com/ai-dynamo/dynamo/pull/18053

llama.cpp：1 条，新支持一个多模态模型

llama.cpp 合入 #31819。 mtmd 支持 MageVL-Cowork 模型。 mtmd 是 llama.cpp 里处理多模态的那块。 MageVL-Cowork 是微软的多模态模型。 RoPE（旋转位置编码）还要再打磨。 Metal 上还有个小偏差待修。 来源：https://github.com/ggml-org/llama.cpp/pull/31819

FlashInfer：4 条，全是 cake 内核打磨

FlashInfer 合入 #9101。 FP8 行式 GEMM 加 all-reduce 换了新布局。 覆盖 SM90 的 2 卡、4 卡、8 卡并行。 SM90 就是 H100 那代卡的编号。 FlashInfer 还合入 #9103。 GDN 确定性训练里，q 和 k 改成原地读。 GDN 是一种省显存的注意力算法。 其余两条是修补和开关收口。 来源：https://github.com/flashinfer-ai/flashinfer/pull/9101

vLLM：4 条，全是小活

vLLM 合入 #66228。 MiniMax-M3 的内核版本 bump 了一下。 vLLM 还合入 #66100。 CPU 算子挪了个位置，纯重构。 vLLM 还合入 #65957。 ROCm 的 CI 缓存改了改。 vLLM 还合入 #65743。 删了一批死代码。 来源：https://github.com/vllm-project/vllm/pull/66228

Qoder 是阿里的编程助手应用。 昨天傍晚，它的选择器里多了一个新模型。 名字叫 Qoduck。 个人用户限时免费。 官方页面自己都说，身份还没公开。 阿里云官方账号今天凌晨转发了这条消息。 只留了一句，别问它从哪来。 时间点卡在 Qwen 预告第二天。 有人猜这就是 Qwen 4。 也有早期对比说，连 Qwen 4 Flash 都不是。 没有参数，没有跑分，没有价格。 先当个彩蛋看，别当官宣。 来源：https://cellcog.ai/blog/qwen-4-release-date/

Qwen 4 preview：有人自称提前玩到了

WorldofAI 今天发了个视频。 作者说自己拿到了 Qwen 4 preview。 在 Qwen Code 里跑了一圈。 还说合作方手滑发过一张宣传图。 图上写着 100 万 token 上下文。 还支持图片和工具调用。 输入输出 token 免费。 图已经删了，消息没法核实。 作者猜下周发，内测先玩两天。 全是二手传言，看看就好。 来源：https://iamag.it/news/qwen-4-preview-leak-max-test-arena

Saber：Rust 写的新引擎，专跑 AMD 消费卡

Saber 是个新推理引擎，用 Rust 写的。 目标是 AMD 的 R9700 消费卡。 Qwen3.8 27B prefill 每秒 6645 token。 decode 峰值 316 token 每秒。 测试机是两张 R9700，加一颗 9900X。 数字来自 Reddit 帖子，不是官方跑分。 但 AMD 消费卡能跑大模型，值得留意。 来源：https://daily.rclabs.in/trackers/benchmarks

访谈与深度
