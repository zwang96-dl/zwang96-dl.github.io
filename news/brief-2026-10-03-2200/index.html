业内新闻

  • 本轮就一条新料：SGLang 上线了 /v1/decisions 接口。
  • 说人话：这是决策服务的新玩法。
  • 不生成一个字，直接把每个选项的概率读出来。
  • 类比一下：以前每个决策都要先写篇小作文再抠答案，现在直接填表交卷。
  • 原理就一句话：prefill 跑完就收工，读答案位置上 token 的概率值。
  • 整个 token-by-token 的 decode 循环直接砍掉。
  • 对你意味着什么：做分类、路由、打分这种活儿，延迟和成本都低一大截。
  • 而且任何 chat 模型都能用，不用专门训练，不用特殊 checkpoint。
  • 来源：https://github.com/lovedheart/sglang/blob/HEAD/docs/docs/supported-models/decision_models.mdx

访谈与深度

  • Medium 深度长文：「90% 信心不是機率：拆解一個不生成文字的 LLM」。
  • 作者 Tim Wu 解读了 Archer Hume 花一万次 API 调用逆向 TypeSafe Jev 的实验。
  • 实验一：只是把选项顺序调换，正确答案的概率就从 0.84–0.89 跳到 0.93–0.96。
  • 划重点：你的分类器评估流程里一定要加洗牌测试，这件事便宜到没理由不做。
  • 实验二：加一个明显无关的第五选项（比如"坏天气造成的"），原有两个选项的胜负比居然变了。
  • 说白了：模型是把整张选项表当整体读的，选项之间会互相串味。
  • 实验三：confidence 字段只是个算术公式，不是真实的正确概率。
  • 一个很集中的分布，完全可以是很有自信地错。
  • 校准数据：1200 题 MMLU 上 ECE=0.031，校准得不错。
  • 但 990 题挤在 0.9–1.0 这一桶，ECE 被高分桶主导了。
  • 延迟实测：1500 个问题几百毫秒就回来了。
  • 秘诀是所有题目共用同一份 state 的 KV cache（草稿纸只写一份），成本从 Q×S 降到 S。
  • 类比：一个包间共用一份菜单，各人点各人的菜。
  • 补记（9/30）：SGLang 把这套做成了开源实现，官方文档把上面几个坑都写进注意事项了。
  • 选项顺序影响答案、概率会随 batch 组成飘最多 0.07、confidence 只是算术。
  • 开源生态已经跟上：llm2jev（支持 SGLang/Transformers/MLX，还能吃图文）。
  • diffusion-jev-sglang（Jev 加眼睛，做图像决策），s1decide。
  • 都是近两周冒出来的新 repo。
  • 原文：https://medium.com/@changtimwu/90-%E4%BF%A1%E5%BF%83-%E4%B8%8D%E6%98%AF%E6%A9%9F%E7%8E%87-%E6%8B%86%E8%A7%A3%E4%B8%80%E5%80%8B%E4%B8%8D%E7%94%9F%E6%88%90%E6%96%87%E5%AD%97%E7%9A%84-llm-13b18d2decc9
  • Archer Hume 原文：https://archerhume.com/posts/jevs-architecture-unmasked/
