SGLang：17 条，PD 搬 KV 多了道验货是头条

#41056 是 NPU 上 PD 校验的新功能。

PD 就是读题和生成分机器跑。

读题机算完 KV，搬给生成机。

KV 就是解码时留的草稿纸。

搬的过程中万一传坏了，以前发现不了。

现在两边各算一次校验和。

校验和就是一串数字指纹。

对不上，生成机直接拒收。

这招本来只在 CUDA 上有。

现在昇腾 A3 和 A5 也能用了。

代价很小：吞吐最多慢 2.3%。

1 万 token 时只慢 0.5%。

校验一次 5 到 14 毫秒。

你的 PD 评估里可以记一笔。

跨机搬 KV，完整性校验是标配。

#51779 和 #41269 都是投机解码的修补。

投机解码就是小模型先打草稿。

EAGLE 草稿在 DP 注意力下会卡死。

DP 就是把请求分到多组设备上算。

这两条把死锁修了。

#48314 是 GLM-5.3-Flash 的提速。

H20-3e 上 TP8 和 TP4 的配置加进来了。

TP 就是张量并行。

#51725 是打分的新功能。

每个输入位置的 token 概率能单独输出了。

#49554 是 AMD 的提速。

MI355X 上小矩阵启动更快了。

#51763 是 v1.0 分支的 cherry-pick。

release/v1.0.0 分支开始收补丁了。

其余是文档、扩散模型修补和 CI。

来源：https://github.com/sgl-project/sglang/pull/41056

vLLM：7 条，混合模型读题提速是头条

#68673 是 Mamba 的读题提速。

LFM2 和 LFM3 的 ShortConv 层能导出检查点了。

检查点就是中途存下来的状态。

以前开着前缀缓存，长提示还得多跑一步读题。

前缀缓存就是算过的开头不用重算。

现在一步跑完，首字快了很多。

LFM2-1.2B、8K 提示、并发 4。

B300 上首字时间降 76%。

MI355X 上降 32%。

代价是 KV 容量少 0.8%。

准确率基本没变。

这条跟 21点版的 FrontierReplay 是同一条线。

混合模型的前缀缓存正在被一块块补齐。

#68864 加了 Inkling 2 Small 的配方。

H200 上能直接按配方跑了。

配方就是官方给的部署做法。

#58672 是 MoE 的重构。

Quark 的静态 INT8 量化换了新调度。

#57311 是启动提速。

模型信息缓存的保存变轻了。

其余是 CI。

来源：https://github.com/vllm-project/vllm/pull/68673
