AcceptanceAware：草稿模型别练"学得像"，直接练"被接受"

原文：Acceptance-Aware Draft Model Training for Speculative Decoding
arXiv:2609.24150v1，2026-09-21 提交。
作者：Tianhua Xia、Mugilan Ganesan、Yifei Feng、Haiyu Wang、Maximilian Egger、Sai Qian Zhang（NYU、滑铁卢大学）。

人话解读

  • 投机解码这套玩法：小模型（draft，实习生）先写一堆候选 token。
  • 大模型（target，专家）再一次性验收，通过的直接采用。
  • 加速效果全看一个数：接受长度（acceptance length）。
  • 就是一次验收能连着通过几个 token，越多越赚。
  • 以前训练草稿模型，目标都是让它"学得像"目标模型。
  • 用的 KL 散度、交叉熵，本质都是分布拟合。
  • 这篇捅破一层窗户纸：学得像，不等于被接受。
  • 草稿模型故意做得很小，容量不够时只能取舍。
  • KL 让它每个位置都像一点点，验收却只看"连着过几个"。
  • 两者优化目标错位，练的方向就歪了。
  • 更狠的发现：贪心和采样的"验收标准"根本不一样。
  • 贪心验收：草稿 token 必须等于目标的 top-1，对不上直接毙。
  • 采样验收：走拒绝采样，接受概率等于两个分布的重叠面积。
  • 所以一个 loss 打天下行不通，得按验收标准定制训练目标。

核心方法

  • 先搭统一框架：投机窗。一次验收覆盖 γ 个位置。
  • 推导出期望接受长度公式。用的工具是尾和恒等式。
  • 关键洞察：早期 token 的接受率有乘法效应。
  • 第一个 token 被拒，后面写得再好全白搭。
  • 所以 loss 要奖励"从头连着对"，而不是"平均每个位置像"。
  • EAL loss（专配贪心）：a_t 取草稿给目标 top-1 的概率。
  • loss 就是期望接受长度取负，直接最大化它。
  • 实际用时挂在 KL anchor 上：L_KL + 0.1 L_EAL。
  • WTV loss（专配采样）：a_t = 1 - TV(p̃, q̃)。
  • TV 是总变差距离，两分布"不重叠"的部分。
  • 重叠越多，采样验收越容易过，公式直接对应验收机制。
  • 只需一次 draft 前向加一次 target 前向，并行算出全窗。
  • TV 对 q̃ 分段线性、可微，直接当完整目标用，不加 anchor。
  • GRPO 阶段：模拟贪心验收，把窗内真实接受长度当 reward。
  • reward 要去偏：减掉 frozen 参考草稿在同一窗的表现。
  • 同一前缀难度抵消，只奖励"比参考多接受的部分"。
  • 组内标准化优势，PPO 式裁剪更新，3 轮 SFT + 3 轮 GRPO。

关键数据

  • 树状 draft，Qwen3-8B 配 0.6B 草稿，贪心验收。
  • EAL 版拿到 4.503。KL baseline 是 4.494。
  • 再加 GRPO 到 4.514，全场最好。
  • 同一配置切到 T=1.0 采样，画风突变。
  • WTV 拿到 5.750，KL 只有 4.998，提升约 15%。
  • WTV 再加 GRPO 到 5.763，继续涨。
  • T=0.5 采样：WTV 4.780 对 KL 4.304，优势同样明显。
  • 32B 配 4B 草稿，T=1.0。WTV 6.671，KL 只有 5.960。
  • Gemma4-31B 配 E2B，链式 draft，T=1.0。WTV 6.102，KL 5.699。
  • 贪心下各方法咬得很紧，WTV 反而垫底（4.428）。
  • 采样下 WTV 断层领先，贪心下 EAL 系最稳。
  • 结论很干净：loss 必须跟解码方式对齐，错配就白给。
  • 训练数据：6 万条 ShareGPT prompt，目标模型贪心生成回复。
  • 训练成本：2 张 H100，AdamW + cosine 学习率。

跟你研究方向的关联

  • 你在 MI350 上跑 vLLM 吞吐 benchmark，接受长度是核心变量。
  • 它直接决定每次 target 前向能产出几个 token。
  • 线上服务多用采样（温度大于 0），WTV 训练的 draft 正好对口。
  • 一次多接受约 0.7 个 token，吞吐数字会明显好看。
  • 你在评估 SGLang 的 PD 解耦，decode 节点吞吐同样吃接受长度。
  • draft 质量越好，解耦带来的加速放大倍数越高。
  • 你跟踪的 EAGLE/SpecQuant 是推理时加速，这篇是训练时优化。
  • 两条路线不冲突，可以叠加着用。
  • vLLM 里开投机解码走采样模式的话，换 WTV 训的 draft 头是现成收益。

跟你之前看过的内容的呼应

  • FastMTP（vLLM 原生 MTP 头微调）。这篇 loss 可直接套上去训。
  • GrowMTP（RL 在线长出 draft 头）：这篇 GRPO 阶段思路相通。
  • 都是拿接受长度当 reward，而不是拿"像老师"当目标。
  • MTP 自蒸馏那篇（3 倍加速）：蒸馏目标是拟合老师分布。
  • 这篇的观点更激进：拟合分布不如直接优化被接受。
  • LK Losses 是同方向先行者。优化单 token 接受率。
  • 这篇再往前一步：优化整个窗口的期望接受长度。
  • 还考虑了窗口内的连乘依赖，比单点优化更贴近真实验收。

术语表

  • speculative decoding：投机解码。实习生先打草稿，专家一次性验收。
  • draft model：草稿模型。轻量小模型，负责快速猜 token。
  • target model：目标模型。大模型，负责验证草稿对不对。
  • acceptance length：接受长度。一次验收连着通过几个 token。
  • greedy verification：贪心验收。只认目标 top-1，对不上就毙掉。
  • sampling verification：采样验收。走拒绝采样，看分布重叠度。
  • rejection sampling：拒绝采样。草稿先抽一个，目标按概率决定收不收。
  • TV distance：总变差距离。两个分布"不重叠"的部分，越小越像。
  • EAL loss：期望接受长度 loss，专配贪心验收。
  • WTV loss：窗口 TV loss，专配采样验收，直接优化分布重叠。
  • GRPO：组相对策略优化。用接受长度当奖励，再微调一轮。
  • teacher forcing：训练时喂真值前缀，让双方看同一上下文。
  • speculative window：投机窗。一次验收覆盖的连续 γ 个位置。
  • KL divergence：KL 散度。衡量两个分布差异的经典指标。
  • tail-sum identity：尾和恒等式。把期望写成"超过 k 的概率"求和。
  • PPO-style clipped surrogate：PPO 式裁剪目标。限制策略更新步子别迈太大。
