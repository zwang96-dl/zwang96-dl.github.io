框架更新

  • 六家框架这轮都没发正式新版。
  • GitHub API 逐家核验过，全都停在原地。
  • vLLM 还是 v0.30.0，SGLang 还是 v0.5.20。
  • llama.cpp 只有 b11298–b11307 每日快照。
  • 按惯例快照不算正式发版。
  • TRT-LLM 的 v1.3.0rc29 是 prerelease。
  • prerelease（预发布版）也不算正式版。
  • 但 vLLM 仓库里有个 RFC 值得看一眼。
  • RFC（征求意见稿）就是"有个想法大家来讨论"。
  • 编号 #58537，标题叫 KV Context Editing。
  • 想法是：agent 宣布某段上下文"语义上死了"。
  • 引擎就对这段零分配、零搬运、不参与注意力计算。
  • 但原文保持字节稳定，前后缓存复用不受影响。
  • 说白了：agent 扔掉的历史，不再交显存税。
  • 跟你的 prefix caching（前缀缓存）方向直接相关。
  • 链接：https://github.com/vllm-project/vllm/issues/58537

新技术与论文

  • arXiv 9/30 新批次还没进 API 索引。
  • 最新只到 9/29 的批次，窗口内零入库。
  • 补录一篇 9/27 的论文：SuffixReplay。
  • 它专治 hybrid 模型（全注意力+线性注意力混搭）的前缀缓存。
  • 线性层的循环状态（整层压缩成一个向量）没法回退到任意前缀边界。
  • 这篇的思路是"让它忘掉远古历史"。
  • 只存一小段输入当锚点，命中时重放一小段后缀。
  • 质量保留 91.4–100%，存储只要 SGLang 默认方案的零头。
  • 跟你评估 SGLang 时 hybrid 模型的暗坑直接相关。
  • 「值得深读」：中文精读笔记已生成。
  • 含原文 Figure 1/2/10 和 Table 1。
  • 论文：https://arxiv.org/abs/2609.33477
  • 9/28–9/29 那批论文此前各版已报过。
  • 包括 WUSH-KV、DScale、LongSpark。
  • 这轮不重复。
