多模态大模型推理服务简报 · 2026-11-03（21点版）

21点版来了。这轮是小窗口，1.5 小时里没什么大动静。最有料的是 SGLang 的一笔 PD 解耦修复。KV checksum 在两处场景下直接禁用。分别是 DeepSeek-V4 和 HiSparse decode。vLLM 这轮全是 Rust 前端补齐对齐。论文侧 arXiv 撞上 429 限流，批次也刚过。本轮结构性零入库。

框架更新

SGLang 3 笔

#48292：DeepSeek-V4 下 KV checksum 禁用 P/D 解耦就是 prefill 和 decode 分开跑的分工流水线。KV checksum 相当于搬运 KV 时的对账单。在 DeepSeek-V4 和 HiSparse decode 里，账老对不上。这笔 PR 干脆把这两处的校验关掉。跟你的 PD 评估直接相关。 来源：https://github.com/sgl-project/sglang/pull/48292

#48111：投机解码同步默认改 init 投机解码就是小模型先打草稿、大模型再改。这笔把张量并行同步的默认模式换成 init。用 spec decode 的同学，升级前看一眼。 来源：https://github.com/sgl-project/sglang/pull/48111

#48283：调度器 abort 收敛到一个入口 纯重构：排队里的 abort 都收进 RequestRetirer。行为不变，略过。 来源：https://github.com/sgl-project/sglang/pull/48283

vLLM 12 笔

Rust 前端对齐 7 连发（#65369–#65377） vLLM 的 Rust 前端在追 Python 前端的行为。tool_choice=none 时丢掉 tool calls。几个路由返回 501，usage 字段省略。bool 参数拼写兼容。replay 的 tool-call 参数强制转对象。Python 风格 flag 也支持。data-parallel-rank 不再绑定环境变量。都是语义对齐，没有新功能。 来源：https://github.com/vllm-project/vllm/pull/65369（其余依次为 65370、65371、65372、65374、65376、65377）

#65528：AR 投机器 decode 路径清理 投机解码里，自回归猜词器那条 decode 路径做了内部重构。功能不变。 来源：https://github.com/vllm-project/vllm/pull/65528

其余三笔都是 CI 和测试小修，略过。

Dynamo 2 笔

#17977：PD 配方砍掉 decode 端 CPU KV 层 Nemotron 3.5 Super VL 的 PD 解耦配方瘦身了。decode 端的 CPU KV 层直接砍掉。KV 搬运路径更精简。 来源：https://github.com/ai-dynamo/dynamo/pull/17977

#17874：纯文本模型前端直接拒多媒体 纯文本模型收到多媒体输入，以前还要转一圈。现在前端路由之前就直接拒掉。省掉一次无效转发。 来源：https://github.com/ai-dynamo/dynamo/pull/17874

FlashInfer 9 笔全是 cake kernel 微调。#8574 给 Blackwell MSA 做了 prefill 融合。#8594 调优了大规模 MoE 的 GEMM 配置。这两笔跟 serving 沾边，其余略过。 来源：https://github.com/flashinfer-ai/flashinfer/pull/8574、https://github.com/flashinfer-ai/flashinfer/pull/8594

llama.cpp 窗口内 0 个 PR。出了两个每日快照 b12097/b12098。按惯例快照不算正式发版，略过。

版本水位 vLLM v0.33.0、SGLang v0.5.23 都没动。TRT-LLM 还是 v1.4.0rc2，LMDeploy 还是 v0.18.0。TGI 处于维护模式，本轮无动静。
