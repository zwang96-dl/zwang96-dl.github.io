业内新闻

  • DoorDash 也"叛逃"到开源自建阵营了。
  • 它家 GenAI 平台 2023 年就上线，最早买的是 OpenAI、Anthropic 等第三方 API。
  • 后来发现不好玩：账单飙升、模型频繁下线、自定义链路追踪做不动。
  • 现在转投开源模型，用 Modal 做 GPU 云，vLLM 和 SGLang 自己搭推理服务。
  • 结果：每年省下几百万美元，好几个场景准确率还更高了。
  • 说白了，平台抽象做得好，换引擎就像换插头，业务代码不用动。
  • Agent 网关也自己造：每天撑起 30 万次工具调用，接了 50 多个 MCP 服务。
  • 划重点：连 DoorDash 这种规模都觉得买 API 贵了，自建 serving 降本是大势所趋。
  • 来源：https://techgig.com/news/ai/doordash-built-genai-platform-for-velocity-reliability-accountability/134660916
  • SGLang 和三星半导体联手秀了一把肌肉。
  • 场合是上周 Santa Clara 的 AI Infra Summit（AI 基础设施峰会）。
  • 秀的是 SGLang HiCache 的联合优化。
  • HiCache（SGLang 的分级 KV 缓存）：显存当热区，CPU 内存当中转站，硬盘当冷仓库。
  • KV cache（草稿纸）放不下了就逐级下沉，用时再调回来，不用重算。
  • 数据挺猛：同样 GPU 上，token 间延迟降了 3.1 倍，吞吐涨了 2.2 倍。
  • 这条跟你研究的 KV cache 优化正对上，分级缓存这条路三星也在下注。
  • 坦白说：这是 SGLang 官方自己发的成绩单，测试细节还没公开。
  • 独立验证出来之前，先打点折看。
  • 来源：https://www.linkedin.com/company/sgl-project（SGLang 官方 LinkedIn 约 20 小时前的帖子）
