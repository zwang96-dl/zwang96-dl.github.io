1. NVIDIA 的 KVTC：给 KV 缓存做"无损压缩"，压 20 倍精度几乎不掉（值得深读）

  • KV 缓存就是推理时存上下文的草稿纸。
  • NVIDIA 研究员用 KVTC（KV 缓存变换编码）把它压了 20 倍。
  • 思路抄的是多媒体压缩的老办法。
  • 第一步 PCA 解相关（主成分分析，把重复信息摊平）。
  • PCA 基矩阵只在校准集上算一次，之后一直复用。
  • 第二步动态规划分配比特。
  • 重要的特征多给比特，不重要的少给。
  • 第三步 DEFLATE 熵编码打包。
  • 好处：模型权重一个字都不用改。
  • 8 倍压缩下，Qwen2.5-1.5B 每 token 从 29KB 压到 3.2KB。
  • 代码任务精度只掉 0.3 个百分点。
  • 8000 token 的 prompt，首字延迟从 3 秒干到 380 毫秒。
  • 最前 4 个 token 和最近 128 个不压。
  • 压了这两类，精度会崩。
  • 短对话别用：新 token 本来就占大头，压不出效果。
  • 长上下文多轮对话、Agent 反复推理最合适。
  • 优化版会进 Dynamo 的 KVBM（KV 块管理器）。
  • KVBM 是 Dynamo 里管 KV 缓存的模块。
  • 之后兼容 vLLM，开箱即用。
  • 链接：https://venturebeat.com/orchestration/nvidia-shrinks-llm-memory-20x-without-changing-model-weights
  • 论文：https://arxiv.org/abs/2511.01815
  • 中文精读已生成：《KVTC：NVIDIA 的 KV 缓存 20 倍压缩》。

2. WEKA 给 NIXL 开源了个 GPUDirect Storage 插件

  • NIXL 是 NVIDIA 的推理传输库。
  • WEKA 给它写了个存储插件，开源了。
  • 插件走 GPUDirect Storage + RDMA（网卡直连显卡，不经过 CPU）。
  • 数据搬运零拷贝，延迟抖动小了。
  • 8 张 H100 实测读 260 GB/s。
  • 它的 Augmented Memory Grid（增强内存网格）当 Dynamo 的 token 仓库。
  • 延迟接近 DRAM（内存条）。
  • 说白了：KV 缓存 offload（搬出显存）这条路更快了。
  • 链接：https://www.weka.io/article/weka-accelerates-ai-inference-with-nvidia-dynamo-and-nvidia-nixl
