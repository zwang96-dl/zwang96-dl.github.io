核心更新

PD 解耦：长题不再堵队

  • 这版有个新的可选开关。
  • 等 prefill 全算完再分配。
  • 分配的是 decode 的草稿纸。
  • 草稿纸就是 KV 缓存。
  • 它记着算过的中间结果。
  • 以前是边算边占位置。
  • decode 侧一紧张就互相挤。
  • 现在等算完再一次占满。
  • 官方给了端到端数字。
  • 吞吐最高涨 26.8%。
  • p95 首字延迟砍掉 48.9%。
  • p95 就是最慢那批的线。
  • 测试模型是 GLM-5.2。
  • 格式是 NVFP4 低精度。
  • 条件是 decode 草稿纸吃紧。
  • 这条默认不开，要手动开。
  • 跟你的解耦评估直接对口。
  • 值得你第一个上手实测。
  • 另外还有一条搬运修正。
  • Mooncake 提前传 KV 改了。
  • 要等 prefill 完成才开传。
  • 免得传一半又白传一趟。

MI350X：DeepSeek 配投机

  • DeepSeek-V4.1 能上 AMD 了。
  • 覆盖 MI350X 和 MI355X。
  • 架构代号是 gfx950。
  • 你的 MI350X 正在其中。
  • 加速靠的是 DSpark。
  • DSpark 是一种投机解码。
  • 像实习生先打一版草稿。
  • 专家只改错的地方就行。
  • 官方说吞吐最高 1.9 倍。
  • 对照是普通解码的速度。
  • 条件是 4 张 MI350X。
  • 长题首字延迟也降了。
  • 128K 输入从 860 毫秒。
  • 降到 576 毫秒，快三成。
  • AMD 解耦也同步补上了。
  • FP8 统一 KV 能走解耦。
  • 统一 KV 是新草稿纸布局。
  • 还有 PCP 这条新并行。
  • 它让 KV 词元多装 1.55 倍。
  • 吞吐最高再涨 15.8%。
  • 这两条都在 gfx950 上。
  • 你的 MI350X 可以对照测。
  • H200 那边也有大数字。
  • 每卡吞吐最高涨 2.3 倍。
  • 注意那是 H200 不是 H100。
  • 别直接套到你的 H100 上。

投机解码：多条线一起涨

  • MiMo-V2.6-Pro 涨得最猛。
  • 靠 DFlash 投机解码。
  • decode 吞吐涨 1.85 倍。
  • 条件是 B300，不是你的卡。
  • GLM-5.3-Flash 也涨了。
  • DFlash 让它快约 10%。
  • 单并发从 1091.9 词元每秒。
  • 涨到 1199.7 词元每秒。
  • 条件是 8 张 B300。
  • Qwen3.8-Flash-Next 涨 12%。
  • 条件是 B200，同样标明。
  • GLM 还能叠上下文并行。
  • 名字缩写是 DCP 加 MTP。
  • MTP 是多词元一起预测。
  • DCP8 叠 MTP 快 2.1 倍。
  • DCP2 叠 MTP 快 1.8 倍。
  • 条件还是 8 张 B300。
  • 数字好看，但卡不是你的。
  • 你这边先看 MI350X 那条。

HiSparse：草稿纸放内存

  • HiSparse 是分级稀疏缓存。
  • 它把 KV 草稿纸分层放。
  • 这版它支持了投机解码。
  • EAGLE 和 MTP 都能配。
  • 长上下文的草稿纸放内存。
  • 内存就是 CPU 那边的 RAM。
  • 显存不够时靠它兜底。
  • 还支持多步 KV 换入换出。
  • 解耦那边也有一条小账。
  • DSA 索引可以少存一份。
  • prefill 侧 KV 容量涨 11.6%。
  • decode 侧涨 13.7%。
  • 条件是 GLM-5.2 解耦部署。

加载与新模型

  • 模型加载快了 10 倍。
  • 靠新的 InstantTensor 加载器。
  • 冷启动和扩容都会受益。
  • 新模型名单也不短。
  • 有 Cloudflare 的 Clef 系列。
  • 有 Perplexity 的 Decider。
  • 有 EmbeddingGemma 2 向量模型。
  • 还有扩散模型好几个。
  • 混元图像 3.0 也进来了。
  • 苹果 Mac 也能跑 SGLang 了。
  • 走标准 PyTorch 后端。
  • 跟你的服务器评估无关。
  • 多模态有一条结构改动。
  • GLM-V 的视觉塔能切分了。
  • 按注意力 TP 组来切分。
  • TP 是张量并行，分卡算。
  • 视觉塔就是看图的那部分。
  • 这跟多模态分工思路同源。

重要修复与 breaking change

  • 有个静默算错的坑修了。
  • 混合线性模型会恢复错状态。
  • 条件是投机加结构化输出。
  • 两者同时开才会踩中。
  • 是 Baseten 的人发现的。
  • 升级前先把门槛过一遍。
  • Python 必须升到 3.11 以上。
  • 还在 3.10 会装到旧版本。
  • 它不会报错，只会装旧的。
  • DP 注意力参数换了写法。
  • 旧参数改叫 --attn-dp-size。
  • 老写法还能用，但会警告。
  • ChunkCache 已经被移除。
  • 关掉 radix 缓存走新实现。
  • 解耦有个参数语义翻转了。
  • 主机接收阈值 1 是关闭。
  • 0 反而变成总是接收。
  • 老配置填 0 的要改成 1。
  • 这一条最容易踩，划重点。

术语表

  • PD 解耦：prefill 和 decode 分开用卡。
  • KV cache：模型的草稿纸，存算过的中间结果。
  • DSpark：DeepSeek 系的投机解码方案。
  • DFlash：另一种投机解码方案。
  • MTP：一次预测多个词元的技术。
  • DCP：decode 侧的上下文并行。
  • PCP：prefill 侧的上下文并行变体。
  • gfx950：MI350X 和 MI355X 的架构代号。
  • HiSparse：把 KV 分层存放的稀疏缓存。
  • NVFP4：英伟达的 4 位浮点格式。
  • TP：张量并行，一个模型分到多卡算。
  • radix cache：按前缀复用草稿纸的缓存。
