多模态大模型推理服务简报 · 2026-10-29（14点版）

14点版来了，这轮关键词是"租"。 vLLM 给 PD 搬运工 Mooncake 加了续租机制。 EPLB 搬权重也提速了，GB300 上 decode 快 25%。 SGLang 修了个 LoRA 槽位饿死的坑。

框架更新

vLLM：Mooncake 的 KV 租约可以续了 Mooncake 是 vLLM 的 KV 搬运工。 管 prefill 和 decode 之间传草稿纸。 以前 prefill 做完的 KV，480 秒没人取就作废。 忙的时候解码器排队，KV 等不到就被清，请求白做。 现在加了个 opt-in 的租约：解码器活着就续租，死了就早释放。 跟你评估 PD 直接相关，搬运超时这笔账要重算。 来源：https://github.com/vllm-project/vllm/pull/64193

vLLM：EPLB 搬权重提速，decode 快 25% EPLB 是专家负载均衡，忙的专家把活分给闲的。 这次加了 symm_mem 后端，权重直接推到对面显存。 不用中转 buffer，跨节点拷贝约 800 GB/s。 在 GB300 NVL72 上测的。 V4.1-Flash 的 decode 快了 12% 到 26%。 跟你精度门清单里"EPLB 副本未加载"那条对得上。 来源：https://github.com/vllm-project/vllm/pull/62009

vLLM：Engram 宿主表换大页，DP 各 rank 共享 Engram 是 V4.1 的主机内存草稿纸方案。 两层表 2×94.4 GiB，以前各 DP rank 一份。 改走 host-NUMA 的 cuMem，GPU 按 2M 大页映射。 GB200 上随机查表吃 TLB miss，大页正好治这个。 失败自动回落到老路，不会 OOM。 来源：https://github.com/vllm-project/vllm/pull/62359

vLLM：ROCm 两条，DSv4.1 在 AMD 卡上

#63816：NaN 的路由分数排最后，不再选错专家。

以前单核模式加自适应校验，CUDA graph 抓取直接 fault。

#62481：warmup 后监控 FlyDSL 的 JIT 编译。

来源：

  • https://github.com/vllm-project/vllm/pull/63816
  • https://github.com/vllm-project/vllm/pull/62481

SGLang：LoRA 槽位饿死修了 多 adapter 抢槽位时，冷门的 adapter 永远排不上。 实测 1% 的请求首词元要等 90 秒，中位数才 77 毫秒。 新 LoRADrainer 会主动腾退快完事的 adapter。 来源：https://github.com/sgl-project/sglang/pull/46500

SGLang：调度器少发点统计消息 per-request 的输出统计只在可能变化时才发。 第一次输出、被撤回后、结束时，三次就够。 中间行不再重复带，tokenizer 那边也更省。 来源：https://github.com/sgl-project/sglang/pull/47178

SGLang：投机解码的重构 ragged-verify 的 graph tier 推导收敛到一处。 以前三处各算各的，靠注释保持一致。 纯重构，行为没变。 来源：https://github.com/sgl-project/sglang/pull/34038

TRT-LLM：KVCM2 加了稀疏注意力 KVCM2 是新一代 KV 缓存管理器。 这次加了稀疏注意力的 arena 和主机内存池。 跟你关注的稀疏注意力方向对得上。 来源：https://github.com/NVIDIA/TensorRT-LLM/pull/21129

TRT-LLM：Nemotron VL 的 batch 等价改比 logits 图像 batch 和单张跑，结果要对得上。 以前比自由生成的 token ID 和概率。 现在改比 teacher-forced 的 logits，阈值 1.0。 想起今早那篇"温度设 0 还飘"：batch 一变结果就飘。 来源：https://github.com/NVIDIA/TensorRT-LLM/pull/20330
