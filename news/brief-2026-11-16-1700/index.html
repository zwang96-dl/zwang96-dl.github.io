vLLM v0.34.0：草稿纸变大，老执行器退役（值得深读）

这版一共 1061 个提交。

412 位贡献者，120 位是新人。

先说最值钱的一条。

可扩展 KV 缓存默认开了。

KV 缓存就是模型的草稿纸。

以前按估算先划一块地。

现在热身完了看真实空闲显存再划。

地划得更大，缓存装得更多。

MiniMax-M3 在 H200 上。

缓存从 433k 个 token 涨到 672k。

高并发下吞吐更高，首字更快。

代价也有。

部分模型单 token 延迟涨 6–18%。

不想用就加参数关掉。

第二条，老执行器退役了。

Model Runner V1 删了，只剩 V2。

VLLM_USE_V2_MODEL_RUNNER=0 现在启动就报错。

双批重叠也搬到了 V2 上。

双批重叠就是 prefill 和 decode 两批活重叠跑。

第三条，投机解码上了 V2。

投机解码就是先让实习生打草稿。

再让专家一次性改完。

后缀解码现在跑在 V2 上。

不用再装 Arctic Inference 了。

还加了自定义投机方法的插件接口。

提速数字都挺实在。

Step5 在 4 张 GB200 上。

decode 快了 1.95 倍。

GLM-5.3-Flash 吞吐涨 1.6 倍。

GLM-5.3 长 prompt 首字快 1.24–1.40 倍。

运维也加了两个硬货。

检查点恢复来了。

服务能像游戏存档一样断点续跑。

DP+EP 容错缩容也来了。

有卡挂了不用重启，专家自动重分。

升级前先看三条。

默认 block size 从 16 改成 64。

block 就是草稿纸的一页大小。

ROCm 7.2 的镜像没了，只剩 10.0。

huggingface_hub 要求 2.0.0 以上。

新模型一次加了 10 个。

Mistral Large 4 是大头。

总参数 1T，激活 52B。

还有 MiniMax-M3.1-Flash。

和能听会说的 Nemotron-3.5-Transcribe。

精读笔记已经写好，见下面。

来源：https://github.com/vllm-project/vllm/releases/tag/v0.34.0

SGLang：HiCache 接上 DCP，Kimi-K3 补了个计数

#45205 给 HiCache 接了 DSA 的 DCP。

DCP 就是把超长上下文切开分卡算。

HiCache 是跨请求的缓存层。

这次还配了打包的 MTP 草稿器。

MTP 就是一次多猜几个 token 的投机解码。

#50838 修的是 Kimi-K3。

attention DP 下，EP 级的数要传过去。

传给 MegaMoE，数不对就歪。

#50512 是 DeepSeek-V4.1 的提速。

低比例 extend 的 slot 收集一次算好。

不用每次都跟主机同步。

扩散模型也修了两个。

#50638 让 FLUX.3 按 16 像素对齐。

#34514 让 Sana 尊重 --vae-tiling 参数。

其余是 AMD 小修补、CLI 和 CI。

来源：https://github.com/sgl-project/sglang/pull/45205 来源：https://github.com/sgl-project/sglang/pull/50838 来源：https://github.com/sgl-project/sglang/pull/50512

vLLM 发布后又合了 7 个

#67067 给专用 decode 加上 FP8 KV。

FP8 就是把草稿纸的字写小一半。

Muse Spark Open 的专用 decode 更省显存。

#67807 是 Kimi-K3.1-Pro 的配方。

DSpark 草稿器能跑了，B300 基线也修正了。

#65656 给 DeepSeek-V4.1 提速。

候选 prefill 和 decode 改用 CuTe 写。

#59506 修了个崩溃。

beam search 遇到极端参数不再崩。

#65578 把 GELU 和 NVFP4 量化融成一个核。

来源：https://github.com/vllm-project/vllm/pull/67067 来源：https://github.com/vllm-project/vllm/pull/67807 来源：https://github.com/vllm-project/vllm/pull/65656

FlashInfer：MXFP8 乘 MXFP4 的新核来了
