ValueDiff：黑洞变弱的模型，换一套 KV 驱逐规则

原文：ValueDiff: Value-Geometric KV Cache Eviction for Sink-Suppressed LLMs
arXiv:2609.23314v1，2026-09-20 提交。
作者：Junyoung Park、Jungwook Choi、Mingu Lee（Qualcomm AI Research、汉阳大学）。

人话解读

  • 推理时的 KV 缓存就是草稿纸，上下文越长越占显存。
  • 驱逐策略决定撕掉哪页、留下哪页，撕掉的就回不来了。
  • 老方法有个默认假设：开头几个 token 是 attention sink（注意力黑洞）。
  • 注意力天然往黑洞里灌，所以开头几页永远不撕。
  • 但 Qwen3 这类新架构用了 QK 归一化（query/key 各自先归一化）。
  • 归一化把黑洞压弱了，甚至直接压没，老方法的信号源就没了。
  • 旧信号全在 key 那边：key 负责"被点名"，黑洞一没，key 也没特征了。
  • 这篇的关键发现：黑洞越弱的模型，value 向量反而越分散。
  • value 是每个 token 的"内容包"，越不一样越值得留。
  • 所以 ValueDiff 换了打分轴：不看 key，也不看注意力分数。
  • 只看 value 向量离平均值多远，越远越独特，越值得留。
  • 类比：以前按"被点名次数"留人，现在按"观点多特别"留人。
  • 这篇是 KeyDiff 同一团队（Qualcomm AI Research）的续作。
  • KeyDiff 玩 key 的几何，这篇玩 value 的几何，正好凑一对。

图 1：横轴是 sink 率（首 token 抢走多少注意力权重），纵轴是 σV/σK（value 离散度相对 key 的离散度）。趋势很清楚：黑洞越弱的模型，value 相对越分散。GPT-OSS-20B 和 Qwen3.5 在左上角（黑洞≈0、value 主导），Llama 3 在右下角（黑洞强、key 主导）。Spearman −0.76，相关性很强。这就是 ValueDiff 换打分轴的底气。

核心方法

  • 打分公式：s_j = ||v_j − v̄||，v̄ 是缓存 value 的均值。
  • 分数越高，离平均越远，内容越独特，留下。
  • 分数越低，跟大家越像，属于冗余，先撕掉。
  • 全程不用注意力权重，跟 FlashAttention 天然兼容。
  • 理论推导：未来注意力未知时，假设它均匀分布。
  • 这个假设下（最大熵假设），该打分恰好让输出扰动最小。
  • 消融变体一：ValueDiff-Dir，只看方向。
  • 消融变体二：ValueDiff-Norm，只看模长。
  • 结论：完整 L2 版最稳，方向是主要信号，光看模长不靠谱。
  • 评测协议很硬：prompt 按 128 切块，每过一块驱逐一次。
  • decode 阶段每生成一个 token 也驱逐，丢了就真丢了。

关键数据

RULER（8k 上下文，2k 预算）：

  • 7 个黑洞减弱模型，ValueDiff 保住全量精度的 88–99%。
  • 7 个里 6 个拿第一，唯一例外是 Gemma2-2B。
  • Qwen3-4B：95.2%，第一。Qwen3.5-4B：97.6%，第一。
  • Qwen3.5-9B：95.6%，第一。Gemma3-4B：87.6%，第一。
  • GPT-OSS-20B：91.3%，第一。Gemma2-9B：99.4%，第一。
  • StreamingLLM 在 Qwen3.5 上直接崩到 1–2%。
  • 固定留开头的策略彻底失效。

表 1：RULER 结果，数字是相对全量缓存的精度保留百分比。最右列 ValueDiff 在 QK-norm（Qwen3-4B）、门控注意力（Qwen3.5-4B/9B）、可学习黑洞（GPT-OSS-20B）几行几乎全是加粗第一。再看 StreamingLLM 那列：2k 预算下普遍只有 40% 上下，老方法在紧预算下崩得最惨。

LongBench（21 个任务，最长 65k 上下文，4k 预算）：

  • 黑洞减弱模型平均保住 92%，最强旧基线只有 83%。
  • Qwen3.5-4B：92.2%。Qwen3.5-9B：92.1%。GPT-OSS-20B：91.0%。

MATH-500（长思维链推理，预算为平均序列长的 25%）：

  • 所有黑洞减弱模型上，ValueDiff 都是最强非全量方法。
  • Qwen3.5-4B：84.3%，SnapKV 24.7%，TOVA 39.3%。
  • KeyDiff 65.2%，ManifoldKV 62.9%。
  • 跟它们拉开 19–24 个点。

显存与延迟：

  • Qwen3.5-4B、128k 上下文：峰值显存 15.0GB → 8.6GB。
  • 降了 43%。
  • GPT-OSS-20B、65k 上下文：峰值显存降 29%。
  • 这是所有驱逐方法的公共收益，不只 ValueDiff 一家。
  • 打分开销跟 TOVA/SnapKV/KeyDiff 同量级。
  • TTFT 只比最便宜基线慢 3–4%。

失败边界（论文诚实地给了）：

  • Llama 3.1/3.2 这类黑洞强、key 主导的模型，KeyDiff 更强。
  • Qwen2.5 是个例外：各层几何差异太大，value/key 方法全崩。
  • 四象限结论：只有黑洞结构完整且 key 主导时，KeyDiff 才赢。

图 2：横轴 bos-cosim（开头 key 跟内容 key 均值的相似度，负值=经典黑洞结构），纵轴 σV/σK。颜色表示 ValueDiff 超过 KeyDiff 的百分点，红色=ValueDiff 赢。红点占了第 I、II、IV 象限；KeyDiff 只在左下第 III 象限（黑洞结构完整、key 主导）守住阵地。三个 benchmark 结论一致：几何形状决定了该用哪边。

跟你研究方向的关联

  • 你现在主力评估 Qwen3，而 Qwen3-4B 正是这篇的 QK-norm 代表模型。
  • 黑洞变弱 → 老驱逐方法在你这批模型上会系统性失灵，这篇是直接证据。
  • 你在看 SGLang 的 PD 解耦：KV 要在 prefill/decode 节点之间搬。
  • 缓存压得越小，搬运越便宜，解耦的收益越大。
  • 驱逐发生在 prefill 的每个 block 边界（128 切块），跟 chunked prefill 是同一套世界观。
  • 都是"边算边扔"，这篇的评测协议可以直接映射到你的 serving 场景。
  • ValueDiff 不依赖注意力分数，跟 FlashAttention 不打架，工程落地阻力小。
  • 这篇也给 decode 端提了个醒：做驱逐时看 value 几何，可能比看历史注意力分数更靠谱。
  • 因为后者在 block 边界上是"用过去猜未来"，top-256 重合度只有约 0.4。

跟你之前看过的内容的呼应

  • KeyDiff：同一团队的前作（NeurIPS 2025），玩的是 key 的几何。这篇是它的 value 版续作，两篇对照看最有味道。
  • BeaconKV：用"信标查询"预测未来谁会被重访，是注意力分数派。这篇恰恰证明：在 block 边界上"过去的注意力分数"猜未来并不可靠。两条路线正好对打。
  • KVTC：NVIDIA 的 20 倍无损压缩，是"把纸变薄"；ValueDiff 是"撕掉哪页"。一个压缩、一个驱逐，维度正交，可以叠。
  • py-kvcache：回答"外部缓存值不值"；这篇回答"缓存里留谁"。一个管存哪儿，一个管留谁。

术语表

  • attention sink（注意力黑洞）：开头 token 天然吸走大量注意力，像黑洞。老驱逐法靠它定"必留"位。
  • QK 归一化：query 和 key 各自先归一化再算注意力。Qwen3 标配，副作用是压弱黑洞。
  • gated attention（门控注意力）：注意力输出再过一个可学习的门加权。Qwen3.5 的架构，黑洞同样弱。
  • logit softcapping：用 tanh 把注意力 logit 钳住。Gemma2 的做法，也是黑洞抑制器。
  • learned attention sink（可学习黑洞）：专门学一个 logit 当"垃圾桶"吸多余注意力。GPT-OSS-20B 用它。
  • σV/σK：value 离散度除以 key 离散度。大于 1 说明 value 信息更丰富，是 ValueDiff 主场。
  • sink 率：多少比例的 head 里首 token 拿走超 0.3 权重。越接近 0 黑洞越弱。
  • bos-cosim：开头 key 跟内容 key 均值的余弦相似度。负值=开头格格不入=经典黑洞结构。
  • block prompt processing：prompt 按小块处理，每块结束驱逐一次。长 prompt 下 prefill 也能控显存。
  • dense：全量 KV 缓存、不驱逐的对照组。"保留 xx%"都是相对它。
  • 最大熵假设：对未来一无所知时，假设各种可能等概率。这篇用它导出打分公式。
