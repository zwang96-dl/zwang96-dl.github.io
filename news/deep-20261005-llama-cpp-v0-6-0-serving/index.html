llama.cpp v0.6.0：投机解码链路地基重写，MTP 草稿头实战落地

原文：llama.cpp GitHub release notes（2026-10-05 发布，v0.6.0）
数据源：https://api.github.com/repos/ggml-org/llama.cpp/releases/tags/v0.6.0
说明：release notes 无关键图表（vLLM v0.31.0 笔记同例），以下为文字精读。

人话解读

  • llama.cpp 今天发了 v0.6.0。
  • 这是它改成每日快照后，第一个正经版本号。
  • 上次正式发版还是 b11027 时代，快照按惯例不算发版。
  • 这次内容很实在：批处理 API 重写、MTP 投机解码、Metal 两笔加速。
  • 一句话：它在给"一次猜多个 token"这条路铺地基。

核心更新点

  • 新 API llama_batch_ext，配 llama_process()。
  • 一个 batch 里能混装 token 和 embedding（词向量）。
  • 每个 token 还能带"状态" embedding。
  • 这是给 MTP（多 token 预测）模型用的。
  • deepstack 模型也用得上。
  • 例子、投机解码、mtmd（多模态处理模块）、server 全迁到新 API。
  • MTP 简单说：模型一次前向，顺手多猜后面几个 token。
  • Qwen4Exp 吃上这套：MTP 投机解码正式可用。
  • 投机解码还修了几个 bug：simple draft 和 MTP 的概率采样。
  • n-gram 草稿截断后被误拒的问题也修了。
  • Metal 端：F16 KV 的 flash attention 新核。
  • flash attention 是一种省显存的注意力算法。
  • few-row MMA 矩乘核：专为投机解码和批量解码优化。
  • 苹果 GPU 上矩乘最高快约 3 倍。
  • MMA 是矩阵乘累加指令，GPU 算矩阵乘法的硬件原语。
  • 量化线：新增 llama_prec_policy。
  • 还有模型驱动的 W4A4（NVFP4/MXFP4）矩阵乘路径。
  • 新模型支持：GLM-5.3-Flash（GLM5-Next）。
  • 它是 320B 图文混合模型。
  • 还有 Clef 决策模型、Ling 3.0 VL。
  • server 新增 /v1/systemone 决策模型 API。
  • 支持六个决策模型：laya、julia-1、lev。
  • 还有 openjev、kev、nimble。
  • /v1/embeddings 现在接受带类型的视觉/音频/视频输入。
  • ggml 升到 v0.26.0。
  • Web UI 大改版，接了 Hugging Face Hub 数据层。

关键数据

  • Qwen4Exp 吃上 MTP 投机解码。
  • DGX Spark 上 decode 快约 1.5 倍。
  • 苹果 GPU few-row MMA 矩乘：投机/批量解码场景最高快约 3 倍。
  • GLM-5.3-Flash：320B 图文混合模型。
  • 架构是 KDA/DSA 混合 + mHC + MoE。
  • session 格式升级：LLAMA_SESSION_VERSION 11，LLAMA_STATE_SEQ_VERSION 4。

跟你研究方向的关联

  • MTP 草稿头 = 内置的投机解码，不用另养小模型。
  • 这跟 SGLang 那边的 MTP/EAGLE 路线是同一道题，可以对照看。
  • batch API 重写说明了一件事。
  • MTP 和 deepstack 需要"token 带状态"的新表达。
  • 你评估 P/D 解耦时若碰 hybrid/MTP 模型。
  • 这个 API 设计值得参考。
  • Metal 两笔加速跟你 Mac 本地跑模型直接相关。
  • W4A4（NVFP4/MXFP4）是量化线的下一个落点，vLLM 那边也在跟进。
  • 决策模型 API（/v1/systemone）跟 vLLM Decision 2.0 是同一赛道。

术语表

  • MTP（multi-token prediction，多 token 预测）。
  • 一次前向猜出后面好几个 token，给投机解码当草稿。
  • llama_batch_ext：新的批处理数据结构。
  • 它让 token 和 embedding 混装。
  • deepstack：把中间层状态也拿出来用的模型结构。
  • W4A4：权重和激活都压到 4bit 的量化格式。
  • NVFP4/MXFP4：NVIDIA 和 OCP 推的 4bit 浮点格式。
  • 决策模型：不生成文本、只输出分类/打分概率的小模型。
  • draft（草稿）：投机解码里小模型先写的候选 token，大模型再验。
