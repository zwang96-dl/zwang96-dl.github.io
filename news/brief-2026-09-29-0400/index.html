多模态大模型推理服务简报 · 2026-09-29（04点版）

框架更新

  • TensorRT-LLM 凌晨发了新版本 v1.3.0rc29。
  • 这是预发布版（RC），正式版还没到，先别上生产。
  • 跟你研究最相关的：P/D 解耦修了 KV 传输的 bug。
  • P/D 解耦就是 prefill 和 decode 分开部署，像流水线分工。
  • KV 就是模型推理时的草稿纸，两个车间之间搬运时出过岔子，这版修好了。
  • 草稿解码（speculative decoding）也有更新。
  • 先让小模型打草稿、大模型负责改，现在支持了 FP8 和 FP4 的 MLA（DeepSeek 系用的注意力变体）。
  • 模型支持方面，加了 Qwen3.5 的全局 FP8 量化。
  • FP8 是 8 位浮点，比 FP16 省一半显存。
  • Gemma4 的视觉位置编码也优化了，省掉一次矩阵乘。
  • 改动清单：https://github.com/NVIDIA/TensorRT-LLM/releases/tag/v1.3.0rc29
  • vLLM、SGLang、LMDeploy、llama.cpp、TGI 这轮都没新版，GitHub API 逐家核验过。
