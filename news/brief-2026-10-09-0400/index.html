框架更新

llama.cpp b11521（02:54 PDT）：

  • llama-server 换默认端口了：8080 改成 9931。
  • llama-server 是 llama.cpp 自带的推理服务器。
  • 脚本里硬写 8080 的，升级后会连不上。
  • 换句话说：默认门牌号换了，老地址没人应门。
  • 链接：https://github.com/ggml-org/llama.cpp/releases/tag/b11521

llama.cpp b11518（02:26 PDT）：

  • Mac 上的 llama.cpp 注意力算得更快了。
  • Metal 是苹果的 GPU 加速接口。
  • 这次 Metal 后端加了 head size 128 和 96 的新内核。
  • Flash Attention 是一种更快的注意力算法。
  • Mac 上跑模型的注意力计算会更快更省电。
  • 你主要用 vLLM/SGLang 跑 H100，这条跟你关系不大。
  • 链接：https://github.com/ggml-org/llama.cpp/releases/tag/b11518
  • 其余五家全部静默。
  • vLLM 停在 v0.31.0，SGLang 停在 v0.5.21。
  • TensorRT-LLM 停在 v1.3.0rc29。
  • LMDeploy 停在 v0.18.0，TGI 归档只读。
  • 全部经 GitHub releases API 亲手核验。
