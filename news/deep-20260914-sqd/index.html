SQD：按注意力类型再切一刀，异构解耦新思路

原文：Rethinking Heterogeneous System Disaggregation for Subquadratic Attention
arXiv:2609.13134v1，2026-09-14 发布
作者：Arya Tschand（Harvard）等，NVIDIA 团队（Ritchie Zhao、Oreste Villa、Karu Sankaralingam 等）
原文链接

人话解读

现在的解耦都是按"算子类型"切的。P/D 解耦按阶段切，AFD 按 attention 和 FFN 切。

这篇说：切法错了。前沿模型都在用次二次注意力（稀疏、线性、滑窗），它们的算术强度跟传统 dense attention 完全不是一回事。

按算子类型一刀切，就像按"部门"分工，不看每个人实际干啥。SQD 改成按"注意力是不是二次的"来切 decode，这才是看活分工。

核心方法

  • 切分依据换了：不再看算子类型，看算术强度和内存 footprint。实测发现只有 FFN 的算术强度随 batch 涨，attention 类算子都不涨（见 Figure 3）。
  • 稀疏注意力模型：把 top-k 选择和 top-k 注意力+FFN 分开。前者要扫全量 KV，内存大，留 GPU。后者 footprint 固定，搬上 SRAM-only 的 ASIC。
  • 线性/滑窗注意力模型：把 dense attention 层和次二次层+FFN 分开。前者跟 prefill 放一起留在 GPU，后者搬 ASIC。
  • 通信更稀疏：AFD 每 token 每层要传两次 activation。SQD 只在层组边界传两次，通信量少得多。
  • 藏延迟的缓存：利用 shared-indexer 层之间的 top-k 局部性，设计了延迟感知的 top-k 稀疏 attention 缓存。通信延迟被流水线藏掉，大部分层零开销。

*图注：左=标准 P/D 解耦，KV cache 整份搬一次，decode 还是整块。中=Attention-FFN 解耦，decode 的 attention 留 GPU、FFN 搬 ASIC，每 token 每层传两次 activation。右=SQD，prefill 加二次注意力 decode 层放 GPU，次二次注意力加 FFN 放 SRAM-only ASIC，每 token 每层组只传两次。说明：切分依据从"算子类型"换成了"注意力的算术强度和内存特征"，通信模式也因此变稀疏。*

关键数据

  • 能效：8×B200 代理系统实测，tokens/J 提升 GLM-5.2 +53%、Nemotron 3 Ultra +31%、Gemma-4 31B +56%。对比的是最强的纯 GPU 基线。
  • 功耗：SQD 系统 41.1kW，只有纯 GPU 的 57%。吞吐保留 63-97%，属于拿小幅吞吐换大幅省电。
  • Rubin+LPX 解析模型：同功率预算下，延迟收紧 1.2-1.5 倍。吞吐最高是 attention-FFN 解耦基线的 3.6 倍。
  • GLM-5.2：比 attention-FFN 解耦好 2.9-3.6 倍。这是 SQD 最大的单项领先。
  • 范围限定：结论针对 MoE 和次二次注意力模型。传统 dense 模型吃不到这么多红利。

*图注：GLM-5.2、Nemotron 3 Ultra、Gemma-4 在 chat、RAG、agentic 三种负载下的实测。上排功耗：SQD（绿）只有纯 GPU（灰）的 57% 左右。中排吞吐：SQD 保留 63-97%。下排 tokens/J：绿色数字是相对纯 GPU 基线的提升，GLM-5.2 最高 +56%。说明：省电是确定的，吞吐基本保住，能效提升在 agentic 长上下文负载上最明显。*

跟你的研究方向的关联

  • 解耦粒度是变量：你在单卡 MI350 上评估 P/D 解耦。这篇提醒你，P/D 只是第一刀。decode 内部还能按注意力类型再切一刀。
  • 测的时候分层看：评估 P/D 解耦收益时，把 dense attention 层和稀疏/线性层的贡献分开记。混在一起看会低估稀疏部分的收益。
  • 异构思路可借鉴：GPU 干重的（prefill、dense attention），轻量专用单元干轻的（次二次 attention、FFN）。单卡上就是"不同 kernel 配不同并行策略"的思路。
  • 跟 LCLM 一条线：LCLM 压 prefill，SQD 拆 decode。两者都是"别把 attention 当整块看"，只是下手的位置不同。

术语表

  • 次二次注意力（subquadratic attention）：计算量随序列长度增长比平方慢的注意力。包括稀疏、线性、滑窗等变体。
  • SQD（SubQuadratic Disaggregation）：按注意力是否为二次来切分解耦。本文提出的方法。
  • AFD（Attention-FFN Disaggregation）：把 decode 的 attention 和 FFN 分到不同硬件上的解耦方案。
  • SRAM-only ASIC：只有片上 SRAM、没有 DRAM 的专用芯片。访存快但容量小，适合 footprint 固定的算子。
  • LPX：论文里的 SRAM-only 推理芯片代号，跟 Rubin GPU 搭配做异构。
  • 算术强度（arithmetic intensity）：每个字节访存能换多少次计算。越高越不怕显存带宽瓶颈。
  • tokens/J：每焦耳能量能吐多少 token。能效指标，越高越省电。
