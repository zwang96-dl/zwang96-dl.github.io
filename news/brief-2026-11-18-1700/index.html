vLLM：8 条，多模态占了两条

#67995 是多模态的活。

--limit-mm-per-prompt 现在能按模态关了。

关的是 embed 输入。

embed 输入就是编码器吐出的向量。

按模态开关，省显存更精细了。

#68200 也是多模态。

Omni 模型里音频进视频的路子改了。

原来要走一趟主机内存读数据。

现在不用了，少一次来回。

#66574 跟 KV cache 有关。

KV cache 就是推理时的草稿纸。

连接器现在能在启动准备好后收到通知。

#66791 是 Qwen4Exp 的性能活。

SM90 上融合了两个算子。

其余是修补。

#63113 拦住了会超上下文的流式更新。

#68526 是 Ray 执行器的清理。

#68288 是存活监控的小修。

#67812 是内核里 beta 的计算顺序。

来源：https://github.com/vllm-project/vllm/pull/67995

SGLang：6 条，图像生成模型能省显存了

#50440 是扩散模型的活。

qwen-image 的 DiT 在显存不够时改流式跑。

DiT 就是图像生成里的主干网络。

以前整块塞不下就跑不起来。

现在能一块一块流过去。

#45261 是 DeepSeek-V4.1 的活。

SM12x 上默认走 TP8 加 EP8。

TP 就是张量并行，EP 就是专家并行。

#36088 是 AMD 分布式的修补。

#51376 是 tokenizer 的性能活。

采样掩码现在按扁平数组返回。

其余两条是 CI 的调整。

来源：https://github.com/sgl-project/sglang/pull/50440

TRT-LLM：4 条，一条功能三条测试

#22462 是 MegaMoE 调度的功能。

调度时现在会认 dummy all-reduce。

all-reduce 就是多卡之间汇总数据的操作。

其余三条是测试标记和失败用例豁免。

来源：https://github.com/NVIDIA/TensorRT-LLM/pull/22462

llama.cpp：2 条，一修一加

#19590 给 WASM 加了 Relaxed SIMD。

SIMD 就是一条指令同时算多份数据。

#31913 修了 recurrent state 的 sticky NaN。

NaN 就是算出来的非法数字。

粘住不走会把整条推理带偏。

来源：https://github.com/ggml-org/llama.cpp/pull/19590

Dynamo：4 条，两条都跟 P/D 路由有关

#17247 是路由的修补。

prefill 到达前的 decay credit 现在会丢弃。

decay credit 就是 prefill 排队时的衰减额度。

#18597 也是路由的修补。

decode 队列快到期了，prefill 会提前取消。

P/D 解耦就是读题和生成分开跑。

这两条都是在帮调度器少做无用功。

#18222 是 operator 的小修。

#19101 是容器构建的清理。

来源：https://github.com/ai-dynamo/dynamo/pull/17247

FlashInfer：2 条，一快一修

#9327 是性能活。

FP4 自调优时编译 worker 现在能复用。

自调优就是自动试参数找最快配置。

#6711 是 decode 的修补。

片外元数据现在会被拒绝。

来源：https://github.com/flashinfer-ai/flashinfer/pull/9327
