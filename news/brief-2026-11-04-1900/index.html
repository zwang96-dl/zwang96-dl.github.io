新技术与论文

arXiv Nov 4 的日批上线了。 17点版去看的时候还没上，这轮补上。

「值得深读」Runway：57B 视频模型跑 24fps 实时对话

Runway 的视频对话角色，虚拟人边听边说边动。 57B 参数的自回归视频扩散 transformer。 4 块 H100，704×1088。稳态跑到 24.5fps。 主线是"读时做的活挪到写时做"。 RoPE 和 FP8 量化只在写 cache 时做一次。 cache 维护从 69.7ms 压到 6ms。 优化前 240.9ms 一步，优化后 159.3ms。 生产跑了七周，99.5% 会话达标。 精读笔记已生成，见深读目录。 原文：https://arxiv.org/abs/2611.05642

Metastability：PD 解耦的雪崩陷阱

这篇跟你 PD 评估直接相关。 一次短时流量高峰，能让 PD 解耦引擎瘫痪一小时。 SGLang 上实测：10 分钟高峰后 goodput 掉 88%。 人走完了，系统还缓不过来。 元凶是正反馈：请求变慢，会话堆积。 堆积拉低缓存命中率，命中率低又更慢。 给你的 PD 评估提个醒：压测要加"高峰后恢复"这一档。 来源：https://arxiv.org/abs/2611.02543

EchoKV：KV 淘汰的自我纠错

KV cache 淘汰不只是给 token 打分。 打分用的"草稿工作区"错了，后面全歪。 EchoKV 用迭代反馈修工作区。 LongBench 上跨文档找证据的任务涨得明显。 来源：https://arxiv.org/abs/2611.05903

ReCR：视频解码时，哪些历史帧该给模型看

自回归视频生成里，过去的帧是未来的证据。 ReCR 把"给解码器看哪些过去帧"当成显式决策。 用模型自己的内部表示挑上下文。 训练都不用，即插即用。 来源：https://arxiv.org/abs/2611.04164

PARC：端侧多模态智能体的显存瘦身

手机上跑多模态智能体，显存不够。 两招：剪枝按加速器核心数对齐。 视觉历史按生命周期分开管。 来源：https://arxiv.org/abs/2611.02601

DepthGraft：跨层 KV 复用还是结构正则化

跨层 KV 共享不只是省显存。 深层到浅层的梯度直通，让 key 的检索方向更锐。 来源：https://arxiv.org/abs/2611.03142

闲时 serving 卡拿来预训练

serving 低峰期显卡闲着也是闲着。 这篇用零阶优化拿闲卡做预训练。 零阶就是只跑前向、不用反向。 预训练要更新全部参数，梯度估计会散。 他们的观察是曲率可以救。 来源：https://arxiv.org/abs/2611.02688

循环语言模型的量化比想象中简单

线性循环替代 softmax 注意力。 KV cache 不再随长度涨。 但量化那套是按 Transformer 调的。 这篇把循环模型的量化设计空间理了一遍。 来源：https://arxiv.org/abs/2611.01864

Dory1.0-4B：循环 GPT，一份权重多档算力

4B 参数的循环 transformer。 循环块跑几遍可调。 一份 checkpoint 适配不同算力预算。 NVFP4 预训练 4.5 万亿 token。 来源：https://arxiv.org/abs/2611.03998

访谈与深度

Simon Mo 新 talk：agent 负载改写 vLLM

Simon Mo 是 vLLM 创始团队的。 11 月 2 日，Modal 的 Runtime 2026 大会。 他讲了 18 分钟。 核心数据：agent 会话中位读 14.2 万 token。 只写 444 个，循环几十轮。 KV cache 是核心战场。 三招：混合 cache、P/D 解耦、分布式 KV 池。 Codex agent trace 上，吞吐 3.8 倍。 跟你 PD 评估对口，值得看。 来源：https://vllmbangkok.com/en/blog/serving-the-agentic-workload/

Latent Space：llm-d 合并 ThunderAgent

llm-d 把 ThunderAgent 合并了。 agent trace 的首字中位延迟从 50 秒压到 2–4 秒。 吞吐 1.5–2 倍。 OCRia-1，单块 B200，285 干到 2800 tok/s。 靠投机解码加量化加 17 个小优化。 来源：http://latent.space/p/ainews-behind-latent-space-kill-my-saas-jev-ai-in-2026-aiei-shanghai/

实测：8 块 B300 跑 2.8T Kimi-K3

实测帖：SGLang 0.5.23，8 块 B300。 1.56TB 权重全塞进一台机器。 单用户 104 token/s。64 个 agent 会话共 2000 token/s。 整单实验花了 49 美元。 来源：https://medium.com/@willyouzhizou/serving-2-8-trillion-parameter-open-agent-model-kimi-k3-on-8xb300-gpus-f71b4a549fb7
