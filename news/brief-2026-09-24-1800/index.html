业内新闻

AWS 出了个推理网关（HyperPod 专用）。 说白了：这是个 K8s 原生的请求路由器。 HyperPod 是 AWS 的 GPU 集群方案。 划重点：它挑机器不靠轮询。 看的是每台机器的 KV cache（推理草稿纸）用了多少。 排队有多长，LoRA 适配器（可插拔的小模型插件）在不在。 官方说法：首 token 延迟最多降 82%。 p99 的 TTFT（首 token 时间）降 97–98%。 兼容 vLLM 和 SGLang，不用改代码就能接上。 多模型同跑一个集群时，一个入口自动分流。 提醒一句：这条来自社区新闻站 aws-news.com（9/24）。 不是 AWS 官方博客，数字是官方口径，自己测了才算数。 来源：https://aws-news.com/article/2026-09-24-amazon-sagemaker-hyperpod-inference-gateway-for-scalable-llm-inference
