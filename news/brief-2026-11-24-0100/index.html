Dynamo v1.7.0：跨池子路由来了

这是今晚的头条。

763 个 PR，150 个贡献者。

最大的一件是 Global Router。

一个前端能同时管多个推理池子。

发现服务先把池子和路由都登记上。

前端按负载分流，会话还粘在同一个池子上。

说白了，以前一个调度器只管自己那一亩三分地。

现在一个入口能跨池子调人了。

Planner 也加了新本事。

批量排产、池子优先级、实时重调都来了。

重调是实验功能，会回放 trace 找更优配置。

Router 加了按截止时间排队。

快过期的请求先走，过期了直接拒。

KV 抓取也加了提示，只找同组里的源。

Sidecar 终于能顶多节点引擎了。

引擎挂了，正在跑的请求能迁走。

Sidecar 自己重启再注册。

前端还加了语音转文字和批量接口。

多模态那边，SGLang 的 worker 能接图、视频和音频了。

引擎版本有三档。

SGLang 是 v0.5.23。

TRT-LLM 是 v1.4.0rc2。

vLLM 是 v0.33.0。

注意 vLLM 钉在 v0.33.0，比最新版低一档。

这篇标了「值得深读」，笔记在下面。

vLLM：MoE 和稀疏注意力各进一步

#66749 给 Hopper 加了新 MoE 后端。

用 FlashInfer 的 CuTe-DSL 写的，不量化。

MoE 就是专家混合模型，一次只请几个专家干活。

#68321 给两个模型开了新核。

HYV4 和 V4-Flash 都能用。

核是小头的 FlashMLA，跑在 SM90 上。

FlashMLA 是 DeepSeek 的 MLA 加速核。

MLA 是 DeepSeek 用的压缩注意力。

SM90 就是 Hopper 这一代。

#69332 修了 DSA 索引器的预填问题。

DSA 是 DeepSeek 用的稀疏注意力。

#69132 是 KV 卸载的修补。

P2P 搬运里去掉空转的写任务。

写量统计也不再虚高。

#63805 和 #59371 都是 RL 方向的。

一个加了 Connex 权重传输后端。

权重传输就是把新权重发到推理卡上。

一个在权重更新完时先对一遍基线。

#67021 让 Kimi K3 的工具参数边来边吐。

不用等整段攒齐再给。
