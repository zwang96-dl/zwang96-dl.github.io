新技术与论文

  • 推理引擎赛道来了个新玩家：Magnitude。
  • Magnitude 是 YC 今年夏季孵化的公司。
  • YC 是硅谷最有名的创业孵化器。
  • 它把自家推理引擎开源了，Apache 2.0 协议。
  • 打法是"量体裁衣"：在本机上编译调优 kernel。
  • Kernel 是跑在芯片上的小计算程序。
  • 别家发均码版，它按你的硬件现场定制。
  • 官方宣称：比 llama.cpp 快最多 2 倍。
  • 苹果 Metal 上 decode 快 92%。
  • Metal 是苹果的 GPU 编程接口。
  • NVIDIA 卡上（CUDA）快 19%。
  • CUDA 是 NVIDIA 的并行计算平台。
  • Decode 是模型逐字吐词的阶段。
  • 场景是本地跑 agent 用的小模型。
  • 底子是 Rust，搭在 llama.cpp 上。
  • 支持苹果芯片、NVIDIA、AMD 和纯 CPU。
  • GitHub 已经攒了 6200 多个 star。
  • HN 上 194 分、97 条评论，讨论很热。
  • HN 是程序员爱逛的技术论坛。

  • 本地 serving 也在卷 kernel 级优化。
