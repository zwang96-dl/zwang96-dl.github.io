P2P：视觉计算按层"剪枝"，token 一个不砍

  • 原文：From Patching to Pruning Visual Computation in Vision Language Models
  • 作者：Rahul Chowdhury、Pu Zhao、Yanzhi Wang（Northeastern），Timothy A Rupprecht（EmbodyX），Xuan Shen（浙江大学），Shaoyi Huang（Stevens）
  • 链接：https://arxiv.org/abs/2610.03389v1
  • 发布：2026-10-02（arXiv），cs.CV

一句话人话

VLM（视觉语言模型）推理时，每层都要给每个视觉 token 算注意力投影。

其实很多层的"视觉专属计算"是冗余的。

直接用一个预存的"平均向量"糊弄过去，精度几乎不掉。

P2P 找出哪些层可以糊弄，推理时跳过它们的矩阵乘法。FLOPs 直接砍掉 55%。

解决什么问题

视觉 token 是 VLM 推理的成本大头。

一张图变成几百上千个 token，每层 decoder 都要反复算它们。

现有加速法（FastV、PyramidDrop）走的是"砍 token"路线。

它们的问题：早层看着不重要的 token，后面可能变关键。

砍了就回不来了，这个决定不可逆。

P2P 换了个思路：token 一个不删，只剪"计算"。

它来自 activation patching（神经元干预诊断技术）：把某层的输出替换成参考值，看精度掉多少。

精度不掉，说明这层没干多少"视觉专属"的活。

诊断工具，第一次被改造成了推理加速框架。

核心方法

第 1 步：Calibration，算"平均脸"

  • 拿一个小的 calibration 集，跑一遍冻结的 VLM。
  • 对每一层、每个模块（注意力投影、MLP 投影），算视觉 token 输出的均值向量。
  • 这个均值向量叫 prototype（原型向量），就是这一层的"平均脸"。
  • 每层的"平均脸"各存一份，推理时随用随取。

第 2 步：Validation，前后两轮"扫雷"

  • 在另一批 validation 集上做累积式扫雷。
  • Forward sweep：从第 0 层开始，逐层把输出替换成"平均脸"。
  • Backward sweep：从最后一层倒着往前，同样逐层替换。
  • 每次记录精度掉多少，找到两个边界：前面几层可压、后面几层可压。
  • 安全层集合 = 前缀层 ∪ 后缀层，中间那一"腰"不动。
  • 选层规则很简单：累积替换后精度还在容忍度 τ 之内就行。
  • τ 是全篇唯一的旋钮，越大压得越狠。

第 3 步：推理时"偷工减料"

  • 安全层里，视觉 token 的注意力/MLP 投影直接填"平均脸"。
  • 矩阵乘法整个跳过，不算了。
  • 文本 token 照常算，其他层也照常算。
  • 关键：序列长度、token 顺序、位置信息、注意力 mask、残差通路，全都不动。
  • 跟砍 token 的方法比，它对 serving 栈完全无侵入。
  • vLLM、SGLang 的 batching 和 KV 管理都不用改。

可选：P2P-aware 微调

  • 压得太狠掉精度时，可以加 LoRA（轻量微调）补回来。
  • 微调直接跑在"被压过的计算图"上，让适配器学会补偿。
  • 主结果都是 training-free 的，微调只是备选项。

关键数据

  • 测了 4 个 VLM（Qwen2.5-VL、LLaVA 两家，3B/7B/13B），7 个多模态 benchmark。
  • 3% 容忍度：保留约 94% 的精度，FLOPs 降 55%。
  • 1% 容忍度（保守档）：精度保留 97.7%，FLOPs 降 43.2%（LLaVA-7B）。
  • 13B 上 1% 档：精度保留 98.1%，FLOPs 降 32.8%。
  • 3% 档 LLaVA-7B：FLOPs 从 30.8T 降到 12.6T，降幅 59.1%。
  • 5% 档更狠，但精度开始明显滑坡，不推荐默认用。
  • 默认推荐 τ=3%，精度和效率的平衡点。

关键发现：视觉计算在深度上"两头轻、中间重"

  • 早层和晚层，视觉 token 的专属计算很少。
  • 早层只做浅层编码，后面靠残差流里的信息就够了。
  • 中间层（比如 36 层模型的 14–21 层）干了真正的视觉整合。
  • 晚层直接读残差里已有的视觉信息做推理。
  • 换句话说：VLM 的视觉处理是"分段流水线"，不是均匀分布。
  • 这个发现本身，比加速技巧更有长期价值。

跟你的研究方向的关联

  • 你在评估 SGLang 的 P/D 解耦，多模态还要考虑 encoder/prefill/decode 资源分离。
  • P2P 的层级分析直接给出了"哪里可以省"的地图。
  • 早层视觉计算少，意味着 encoder 输出进 decoder 后，前几层可以配更少的算力。
  • 剪的是计算不是 token，KV cache 的形状完全不变。
  • 这对 prefix caching 和 PD 解耦的 KV 交接都是好消息：不用改传输协议。
  • τ 是单旋钮，天生适合塞进 autotuner 的搜索空间。
  • 跟 VETO 那篇（双轴 token 压缩）是互补路线：一个剪计算，一个剪 token。
  • 两个可以叠加，但先各做各的验证，别一次全上。

术语表

  • VLM（视觉语言模型）：能看图、能答题的大模型。
  • activation patching（神经元干预）：把某层输出换成参考值，看精度变化的诊断法。
  • prototype（原型向量）：某层视觉 token 输出的"平均脸"。
  • tolerance τ（容忍度）：允许掉多少精度的旋钮，默认 3%。
  • safe layers（安全层）：可以"偷工减料"的层。
  • forward/backward sweep（前后扫雷）：从两头逐层试压，找可压边界。
