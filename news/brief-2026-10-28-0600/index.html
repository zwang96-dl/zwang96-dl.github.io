多模态大模型推理服务简报 · 2026-10-28（6点版）

6点版来了。 这轮有个久违的大事。 正式版终于不再全平。 llama.cpp 发了 v0.8.0。 SGLang 还推倒重搭了 KV 池。 本期标一篇深读。

框架更新

llama.cpp 发正式版 v0.8.0 这版等了很久才转正。 以前它只有每日快照。 这次是正式版本号。 主角是 LFM3 全家桶。 LFM3 是 LiquidAI 的小模型。 文本、视觉、音频全齐了。 还能一个模型管语音聊天。 新架构也一口气进了一批。 DeepSeek V4.1 Flash 在内。 稀疏注意力被重做了一遍。 QSA 和 DSA 合到一个算子。 MoE 专家住主机内存时。 新加了 SLRU 缓存管淘汰。 SLRU 是一种分段淘汰法。 服务器多了实时音频接口。 能直接收流式音频输入。 发布说明没给统一跑分。 别自己脑补提速数字。 来源：https://github.com/ggml-org/llama.cpp/releases/tag/v0.8.0

值得深读 — SGLang 重搭统一 KV 池 KV 就是算好的草稿纸。 不同模型的草稿纸不一样。 以前每种组合一套代码。 这次 22 条 PR 一起落地。 15 分钟内整栈合并完。 换成一个路由器管所有池。 分配器也合并成一个。 容量和准入从此统一管。 PD 传输以后都走这套池。 HiCache 的主机层也走它。 验证数字看着很干净。 回放零分歧，传输零差异。 准入 4608 个决定不变。 PD 精度基本守住了。 gpt-oss 是 96.5 到 96.5。 Qwen 是 97.0 到 96.5。 但划重点，作者自己说了。 数字是变基前跑的。 新代码没重跑 GPU 和 PD。 等 0.5.23 出来先复测。 深读：https://zwang96-dl.github.io/news/deep-20261028-sglang-kv/ 来源：https://github.com/sgl-project/sglang/pull/46984

栈里藏着一条 AMD 写错修复 ROCm 的融合写入有个坑。 滑窗视图需要翻译地址时。 它会把 KV 写错地方。 写错还不报错，最阴。 修法是这种情况关融合写。 改由缓存池自己来写。 旧实现 3 个用例失败。 修后 7 个用例全过。 但 AMD 硬件没实测。 只验了路由和资格判断。 来源：https://github.com/sgl-project/sglang/pull/46983

SGLang 的 Rust 前端补了课 Rust 前端以前只管一个 rank。 清缓存只清自己那个。 别的 rank 还留着旧数据。 操作看着成功，其实是假的。 这次控制请求扇出到全员。 每个 DP rank 都要回话。 少一个回话就算失败。 DP 是数据并行，多卡分请求。 来源：https://github.com/sgl-project/sglang/pull/46181 还有一条多模态的小钩子。 处理器能在调度前看结果。 动机明说是给 PD 的 decode 侧。 它要提前拿到展开后的编号。 来源：https://github.com/sgl-project/sglang/pull/46946

vLLM 给 KV 分层加了安全阀 这条跟 P2P 传 KV 有关。 P2P 是两台机器直传草稿纸。 传超时了，请求要立刻失败。 但内存还不能马上释放。 远端可能还在往里写。 早放就会写坏别人的 KV。 新 API 把两件事拆开了。 失败立刻报，释放慢慢等。 等对方确认写不到才放。 还加了两个指标盯着看。 目前还没有层真用上它。 是给后续 P2P PR 铺路。 只有测试计数，没跑分。 来源：https://github.com/vllm-project/vllm/pull/63779

FlashInfer 先量化再发专家 MoE 发激活以前发原稿。 原稿是 BF16，字节大。 现在发送前先量化。 量化就是先压缩再发。 NVFP4 只剩约三分之一字节。 准确说是约 1 除以 3.5。 接收端不用再量化一遍。 顺手把四阶段计时拆开了。 哪段慢一眼就能看见。 正文没给端到端加速。 只有字节量这一个口径。 来源：https://github.com/flashinfer-ai/flashinfer/pull/7426

其余几条一句话带过 SGLang 在昇腾 NPU 上修调度。 三个同步算子曾钉住线程。 单轮最长白等 32.5 毫秒。 改成设备上算，零同步。 那是被去掉的等待成本。 不是端到端加速比。 来源：https://github.com/sgl-project/sglang/pull/46805 TensorRT-LLM 拆了模型库。 新模型的内核单独成库。 用哪个家族才加载哪个。 全量编译的负担小了。 来源：https://github.com/NVIDIA/TensorRT-LLM/pull/20896 FlashInfer 有条训练侧优化。 确定性训练后端最高 1.289 倍。 是训练用的，不是 serving。 来源：https://github.com/flashinfer-ai/flashinfer/pull/7721 LMDeploy 这轮零合并。

DeepInfer 星标还在涨 星标涨到了 23678 个。 4点版时是 23616 个。 两小时涨了 62 个。 代码还是一行没动。 来源：https://github.com/deepseek-ai/DeepInfer

业内新闻

本地显卡能变全球 API 了 OrcaRouter 今天发了新功能。 叫 Orca Connect。 你本地跑的模型接上去。 外面就能当 API 调用。 不用公网 IP，不用转发端口。 vLLM、SGLang 它都支持。 本地推理不收平台费。 云端兜底要你显式开才收费。 具体发布时间没到小时。 只能确认是今天发的稿。 来源：https://www.prnewswire.com/news-releases/orcarouter-launches-orca-connect-turning-any-local-gpu-into-a-free-globally-accessible-ai-api-302921695.html

社区在传 DeepInfer 的边界 有条短视频在介绍 DeepInfer。 它特意说明一个边界。 这版只有离线推理。 不含 KV 缓存系统。 也不含 PD 解耦。 你评估 PD 时记住这点。 别拿它当 PD 的选项。 来源：https://www.instagram.com/reel/DfCYdodkTqv/
