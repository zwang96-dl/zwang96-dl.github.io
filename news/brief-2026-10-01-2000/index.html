新技术与论文

  • arXiv 新日批次这轮入库了，一口气 8 篇。
  • 全部是 2610.x 新 ID，往期没报过。
  • 值得深读：DRelay（2610.01439）。
  • 并行投机解码有个毛病：一个 draft 早错，整条都作废。
  • DRelay 在验证前用全局上下文把错先修好。
  • 直接在 SGLang serving 上实测过。
  • 比 DFlash 等快 8–17%。
  • 对你意味着什么：你在评估 SGLang，这招开箱能抄。
  • 来源：https://arxiv.org/abs/2610.01439
  • HAWK（2610.00623）：视觉语言模型的投机解码器。
  • drafter 是负责打草稿的小模型。
  • 它不喂原始视觉 token，只喂压缩后的视觉隐状态。
  • 还建模了 draft 偏离后 target 的预测漂移。
  • target 是负责拍板的大模型。
  • 多模态接受率更高，正中你研究的交叉点。
  • 来源：https://arxiv.org/abs/2610.00623
  • EchoPress（2610.00412）。
  • 免训练的 KV cache 剪枝。
  • KV cache 是推理时的"草稿纸"，存历史算好的结果。
  • 它用 prefill 阶段现成的 attention 信息估重要性。
  • LongBench 上压缩质量接近 KVzip。
  • KVzip 是要额外 forward 的那款。
  • 长上下文 serving 的显存减负利器。
  • 来源：https://arxiv.org/abs/2610.00412
  • 多模态选择推理（2610.01892）。
  • 多模态搜索智能体把推理改成"选择题"。
  • 不让模型自由生成，改成并行打分选答案。
  • KV cache 共享复用，每步延迟降 90% 以上。
  • 整题推理延迟降 28–54%。
  • 来源：https://arxiv.org/abs/2610.01892
  • TopK-Guided（2610.01763）：训练无关的激活稀疏。
  • 按 token 和层动态分配稀疏预算。
  • Llama-2/3 上精度优于 TEAL 和 WINA。
  • 来源：https://arxiv.org/abs/2610.01763
  • AgSpec（2610.01108）。
  • coding agent 版投机解码。
  • 解决语料里没可复用文本、draft 长度不适配的问题。
  • 来源：https://arxiv.org/abs/2610.01108
  • CAST（2610.00321）：整块 draft 一次前向全打分。
  • 候选拼成树一次验证，模型权重都不动。
  • 只按成本决定树宽。
  • 来源：https://arxiv.org/abs/2610.00321
  • Clock Diffusion（2610.00894）。
  • 半自回归的扩散语言模型。
  • 补上可变长度生成和 KV cache 支持。
  • 给扩散式解码加速探了条新路。
  • 来源：https://arxiv.org/abs/2610.00894
