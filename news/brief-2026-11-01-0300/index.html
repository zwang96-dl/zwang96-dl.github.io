多模态大模型推理服务简报 · 2026-11-01（3点版）

3点版来了，周日凌晨继续安静。 15 个合入，分属三个仓库。 头条跟 prefill 提速有关，带了实测数字。

头条

SGLang：prefill 终于能用可打断的 CUDA 图了

#38943：在解码上下文并行（把解码拆到多卡跑）下支持可打断的 prefill CUDA 图。

CUDA 图是把一串 GPU 操作录下来反复回放，省掉每次调度开销。 之前这个组合会直接启动崩溃，只能回退到 eager 模式。 现在 Kimi-K3 上 2 节点实测。首 token 时间从 404ms 降到 133ms。 吞吐 +14%，解码速度不变。 前缀命中的请求还是回退 eager，后续再做。 跟你研究的 P/D 分离直接相关。这是在把 prefill 和 decode 各自优化玩到极致。 来源：https://github.com/sgl-project/sglang/pull/38943

框架更新

SGLang：P/D 解耦又修了个初始化 bug

#47727：finalize_bootstrap 被包在 assert 里。

Python 的 -O 优化模式会把 assert 整句删掉。 结果请求带着没初始化好的发送器就跑了。 现在改成先执行、再断言结果。 跟你评估的 P/D 解耦是同一块代码。 来源：https://github.com/sgl-project/sglang/pull/47727

SGLang：kv_events 修了两个小毛病

#47732：ipc 端点按 DP rank 加后缀，多卡不再起冲突。

DP 是数据并行（同一份模型复制多份跑）。 关闭时队列满了会抛异常，现在忽略它正常退出。 来源：https://github.com/sgl-project/sglang/pull/47732

SGLang：视频扩散的相机注意力小优化

#47686：Nomas 相机注意力在单块时直接读每帧的 value。

省掉一层中间搬运。 视频生成方向的，不是大模型 serving 主线。 来源：https://github.com/sgl-project/sglang/pull/47686

SGLang：LoRA 测试只是 CI 整理

#45981：简化 LoRA 测试，加了重跑分组。

纯 CI 活儿，无功能变化。 来源：https://github.com/sgl-project/sglang/pull/45981

vLLM：KV offload 删掉没人用的 touch 钩子

#63900：CachePolicy 和 OffloadingManager 里的 touch 方法全删。

KV offload 是把草稿纸（KV cache）搬到 CPU 或磁盘。 之前版本已把"最近使用"逻辑搬到了 on_request_finished。 这笔是收尾清理，LRU 和 ARC 行为不变。 第三方自己写的缓存策略注意。以后必须实现 on_request_finished。 来源：https://github.com/vllm-project/vllm/pull/63900

FlashInfer：7 笔全是 cake 内核 cake 是 FlashInfer 的新内核生成框架。 全是 NVIDIA SM100/SM107 侧的厨房活儿。 RMSNorm、GDN、KDA、MSA indexer 都有调优。 跟你手里的 AMD 卡没关系。 来源：https://github.com/flashinfer-ai/flashinfer/pull/8177
