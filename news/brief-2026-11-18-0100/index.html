TRT-LLM：13 条合入，DSv4.1 性能占了 3 条

#22366 是 DSv4.1 的注意力项。

CSA2（DeepSeek 的稀疏注意力）走张量并行全层选择链。

核内页掩码也一起上了。

#22360 是 DSv4.1 的解码项。

解码批的拆分边界和系数核来了。

#22357 也是 DSv4.1 的。

DeepGEMM 的新核把 X1 留在张量内存。

SM107 的移位核也来了。

#22082 是 GLM-5.3-Flash 的功能项。

分块 8 位量化的目标上了 Blackwell。

#20229 是 KV 缓存管理器的功能项。

C++ 版 v2 学会了按位置管 KV。

双流注意力也一起上了。

这条跟 PD 拆分部署沾边。

剩下 8 条是测试和基建。

来源：https://github.com/NVIDIA/TensorRT-LLM/pull/22366

vLLM：4 条合入，KV 落盘占了两条

#66841 是 beam search 的前端性能项。

beam search 是一次留多条候选的解码。

给已完成的假设历史加了上限。

在线搜索时内存不会越攒越多。

#66278 是 KV 落盘的修补。

磁盘写不满时报“磁盘满了”。

以前只报笼统的 I/O 错误。

#59547 也是 KV 落盘的。

每 rank 独占一块 CPU 内存区。

不再共用同一份复制布局。

剩下 1 条是 ROCm 的 CI 小项。

来源：https://github.com/vllm-project/vllm/pull/66841

SGLang：6 条合入，多模态重构继续走

#46413 是多模态重构第 7 步。

Qwen VL 模型加了新的 token 处理策略。

#47644 是 DFlash 的修补。

草稿采样器只给放得下的 batch 准备。

#47703 修了 trtllm_mha。

图构建的页表改成直接读。

#49514 是 DSV4.1 的修补。

工具消息按预设格式渲染。

剩下 2 条是测试和 CI。

来源：https://github.com/sgl-project/sglang/pull/46413

FlashInfer：4 条，NVFP4 的 MoE 后端来了

#9603 是新功能。

NVFP4 是英伟达的 4 位浮点量化。

它的 MegaMoE EP 后端来了。

跑在 SM107 上。

SM107 就是 Blackwell 新卡。

#9389 也是 MoE 的。

NVLink 屏障改成可选项。

#8853 修了 DSMEM 的读取。

#6458 修了解码的配置拒绝。

来源：https://github.com/flashinfer-ai/flashinfer/pull/9603

Mooncake：6 条合入，修补为主

这轮 6 条，4 条是修补。

#5523 让 RDMA 支持 CUDA DMA-BUF。

没装 nvidia-peermem 也能走。

#2357 把 SSD 和 DFS 的并发读合并了。

#5597 修了优雅卸载卡心跳的问题。

剩下 3 条是传输层和存储修补。

来源：https://github.com/kvcache-ai/Mooncake/pull/5523
