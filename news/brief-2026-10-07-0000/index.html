新技术与论文

1. Foveated Compression：多模态 token 压缩，学人眼看图

多模态模型最烧钱的是视觉 token，一张图进来几千个 token 就没了。 这篇问了个实在问题：token 预算固定时，高清该留给哪块区域。 做法像人眼：中间看得清、边缘模糊。整图先压一遍，再挑 9 个格子里最关键的一格留高清。 21% token 预算下，学出来的选择器比随机挑强。但还是不如直接把整图缩小。 说人话：局部高清不是万能药，全图均匀压有时更划算。 划重点：这篇直接对准你的多模态推理优化线。深读笔记已备好。 https://arxiv.org/abs/2610.07729

2. Lachesis：KV cache 按"寿命"分房，HBM 和闪存各住各的

Agent 跑起来，KV cache 越堆越多。HBM 快但贵，高带宽闪存便宜但写多了会折寿。 这篇的洞察很妙：按 KV cache 的"寿命"分房。短命的住 HBM，写得多也不心疼。 长命的才下沉到闪存。从 agent 编排器的行为里看出来谁命长谁命短。 仿真结果：闪存寿命延长 1.19 到 3.13 倍，连轴跑也撑得过 5 年质保。 说白了：HBM 当草稿纸，闪存当档案柜。跟你研究的 KV cache 优化同一条线。 https://arxiv.org/abs/2610.08378

3. OSFP4：NVFP4 量化再打磨，精度和速度都要

NVFP4 是英伟达的 4 位浮点格式（Blackwell 卡原生支持），存得小跑得快。 但 4 位太糙，直接压会掉精度。这篇把对角平滑矩阵和块缩放一起联合优化。 结果：同类方案里精度最高，prefill 吞吐保住官方 NVFP4 的 94% 到 97%。 换句话说：速度几乎没损失，精度还保住了。量化这条线留个索引。 https://arxiv.org/abs/2610.08231

4. ReFold：agent 上下文太长，折起来但不许扔

Agent 跑长任务，历史记录越堆越长，每次全量重发又贵又慢。 以前的办法要么再调一次模型，要么靠规则，还会把前缀缓存搞失效。 ReFold 不预测不训练：重复内容换成小纸条，办完的轮次折成一句话。 关键是可逆，折错了能从历史里恢复，不会永久丢东西。 实测：token 消耗最多降 2.5 倍，直接插进 ReAct 类框架就能用。 做 agent serving 的可以看看。 https://arxiv.org/abs/2610.07863

5. DySCo：边和云一起跑模型，层数对齐了再拼 batch

手机和 IoT 设备也想跑大模型，但整机塞不下，只能跟云分工。 问题是切分点不一样：边跑几层、云跑几层，互相等，batch 也拼不起来。 DySCo 让各请求都推进到最深的切分点，再把公共后缀拼成一个 batch。 KV cache 留在本地，权重不用反复加载。 边云协同 serving 的新思路，物联网场景可以关注。 https://arxiv.org/abs/2610.08268
