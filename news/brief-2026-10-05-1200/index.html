多模态大模型推理服务简报 · 2026-10-05（12点版）

框架更新

  • llama.cpp 今天早上发了 v0.6.0。
  • 这是它改成每日快照后，第一个正式版本号。
  • 上轮 10 点版检查时它还没发布（09:56 PDT 上线），这轮补上。
  • 最大看点是新的 llama_batch_ext 批处理 API，配 llama_process()。
  • 它让一个 batch 混装 token 和 embedding。
  • embedding 就是词向量。
  • 每个 token 还能带"状态" embedding。
  • 这是给 MTP（多 token 预测）和 deepstack 模型用的。
  • MTP 就是"一次前向多猜几个 token"，给投机解码当草稿。
  • 例子、投机解码、mtmd、server 全迁到这套新 API 上了。
  • Qwen4Exp 吃上 MTP 投机解码。
  • DGX Spark 上 decode 快约 1.5 倍。
  • 苹果用户有福。
  • Metal 新增 F16 KV 的 flash attention 核。
  • flash attention 是一种省显存的注意力算法。
  • few-row MMA 矩乘核：专为投机解码和批量解码优化。
  • 苹果 GPU 上矩乘最高快约 3 倍。
  • 量化线：新增 llama_prec_policy。
  • 还有模型驱动的 W4A4（NVFP4/MXFP4）矩阵乘路径。
  • 新模型：GLM-5.3-Flash（GLM5-Next）。
  • 它是 320B 图文混合模型。
  • 还有 Clef 决策模型。
  • server 新增 /v1/systemone 决策模型 API。
  • 支持 laya、julia-1、lev 三个。
  • 还有 openjev、kev、nimble。
  • 这对你意味着：MTP 内置草稿头又添一个实战样本。
  • 可对照 SGLang 的 MTP 路线看。
  • Metal 那两笔加速，跟你 Mac 本地跑模型直接相关。
  • 来源：PR #24669（batch API）、PR #29761（Qwen4Exp MTP）、PR #29570（Metal FA）、PR #29869（Metal MMA）
  • 其余五家本轮静默：vLLM 还是 v0.31.0。
  • SGLang 停在 v0.5.21。
  • TRT-LLM 稳定版 v1.2.1，预览版停在 rc29。
  • LMDeploy 停在 v0.18.0，TGI 归档只读。
