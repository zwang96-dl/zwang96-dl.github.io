vLLM：注意力核和新模型支持

#69170 把 Triton 注意力的 KV 分块读取向量化了。

KV 就是模型记下来的上下文草稿。

读得更快，解码那一步就更省时间。

#69689 让后端从形状里认出 MLA。

MLA 是一种省显存的注意力结构。

顺手支持了 Youtu-LLM 这个新模型。

#69673 让 MoE 的门控留在原来的精度里。

MoE 就是专家混合模型。

#66342 改了压缩张量量化的加载规则。

剩下 4 条是路由核修补、安全加固和 CI。

来源：https://github.com/vllm-project/vllm/pull/69170、https://github.com/vllm-project/vllm/pull/69689、https://github.com/vllm-project/vllm/pull/69673 和 https://github.com/vllm-project/vllm/pull/66342

SGLang：KV 事件重放加了重试

#48114 让 KV 事件在反压下重试重放。

KV 事件就是缓存变化的通知。

反压就是下游接不住时顶回来。

这跟 PD 解耦里传 KV 那一环直接相关。

#46633 让 GDN 的验证流水线级数可配。

GDN 是一种不用注意力的序列结构。

来源：https://github.com/sgl-project/sglang/pull/48114 和 https://github.com/sgl-project/sglang/pull/46633

llama.cpp：多模态转换修补

#32941 修了 Qwen3-Omni 的模型转换。

Qwen3-Omni 是能听能看的多模态模型。

#32064 让 MCP 工具结果能带图片和音频。

MCP 是模型调外部工具的那套协议。

#32378 拦住了没有 OpenMP 时 CPU 的空转轮询。

#32142 和 #30867 是 ARM 的核优化。

剩下 3 条是 UI 小修。

来源：https://github.com/ggml-org/llama.cpp/pull/32941、https://github.com/ggml-org/llama.cpp/pull/32064、https://github.com/ggml-org/llama.cpp/pull/32378、https://github.com/ggml-org/llama.cpp/pull/32142 和 https://github.com/ggml-org/llama.cpp/pull/30867

来源：https://github.com/flashinfer-ai/flashinfer/pull/9716、https://github.com/flashinfer-ai/flashinfer/pull/9974 和 https://github.com/flashinfer-ai/flashinfer/pull/9468

新技术与论文

五篇预印本同一天出，都冲着推理成本来

Hanging Context 今天汇总了 5 篇新预印本。

主题全是让同一个模型跑得更便宜。

GC-MoE K3 是其中跟你最相关的一篇。

它把 Kimi K3 整层前馈排进一张 CUDA 图。

GB200 上比 SGLang 同轮快 1.13 倍。

比 vLLM 的历史数据快 1.37 倍。

注意：vLLM 那组不是同轮重测。

OnCache 给扩散模型做动态缓存调度。

FLUX.1-dev 上号称快将近 3 倍。

Muted Distillation 让智能体少吐一半 token。

FOLD 是免训练的推测解码新法。

长上下文 256K 内最快 4.22 倍。

CC-Gittins 是给多模型选型省评测钱的算法。

5 篇全是预印本，数字都是作者自报。

来源：https://hangingcontext.com/stories/2026-11-24/inference-costs-attacked-on-five-fronts/ 和 https://arxiv.org/abs/2611.30542
