新技术与论文

SpecPilot（11-02 提交）：让 AI 自己发明投机解码加速。流程像自动化的调参工程师：成本模型先算"离理论上限差多远"，一群 agent 每块 GPU 一个方向并行探索，逐词核验防 agent 偷工减料，经验沉淀成记忆给新部署复用。发现了三个能抄的：无损 12 位权重格式 W12、混合循环模型的树验证、两级验证。单请求从官方版的 4.46 倍提到 10.87 倍，带 batch 从 1.94 倍到 3.93 倍。Berkeley、Princeton、Stanford、NVIDIA 联合出品。 来源：https://arxiv.org/abs/2611.02501

SpecOPD（11-02 提交）：给并行猜词员做 on-policy 蒸馏。关键洞察是监督信号不用串行 rollout 攒，可以按分支并行采。三个并行猜词架构都测了（DFlash、DSpark、DFlash V2）。平均接受长度涨 41.45%，相对普通解码最高 3.56 倍加速。注：DSpark 就是 DeepInfer 的投机解码组件，跟你追的那条线直接咬合。 来源：https://arxiv.org/abs/2611.02846

R²-Omni（11-02 提交）：多模态 KV 的双重瘦身，不用训练。先按时空相似度合并冗余的音视频 token（结构冗余），再按语义敏感度给剩下的分配精度（精度冗余）。内存砍 5 倍，生成质量保住 97.98%，端到端快 1.48 倍。纯多模态方向，跟你的主线最对口。 来源：https://arxiv.org/abs/2611.03247

Fairway（11-01，补漏）：给 prefill 调度做负载感知。核心矛盾：光顾着复用 KV 会饿死贵请求，光顾着公平中位数 TTFT 又涨。解法是双车道：队列短时走"复用优先快车道"，请求等久了切"公平车道"。p99 首字延迟最高比旧的前缀感知调度低 8.6 倍。 来源：https://arxiv.org/abs/2611.02082

谁给草稿纸打分？（11-01，补漏）：KV 驱逐时 token 重要性该看哪一层。21 个模型测下来：浅层看不懂问题，深层已经想偏了，中间 40%–75% 深度那几层打分最准。紧预算下比 SnapKV 高 18–43 个点。注意大模型上默认的本层打分已经接近最优，增益主要在 14B 以下。 来源：https://arxiv.org/abs/2611.02230

SIMPLE 定律（11-02，备查）：LLM 推理能耗的经验定律。偏成本建模，跟你评估的功耗账有关时再看。 来源：https://arxiv.org/abs/2611.03330

业内新闻

Anthropic 发了可验证推理原型 FlashProve（11/2）：用零知识证明（zkSNARK，一种"我算对了但不用给你看权重"的密码学证明）证明"这个回答确实来自指定模型"。Llama 4 Maverick 在单张 H100 上约 110 token/秒，每 1024 token 的证明约 19MB。但证明的 GPU 开销是正常推理的 70–95 倍。目前是研究原型，不是产品。数字全是 Anthropic 自报，没独立复现。 来源：https://blockchain.news/news/anthropic-provable-inference-flashprove-llama-4-maverick

印度 E2E Networks 上线按 token 计费的推理服务 Blaze（11/2）：一个 OpenAI 兼容的 API，聚合了 Nemotron、DeepSeek、Qwen、GLM、Gemma。底座是 NVIDIA Dynamo：KV 缓存感知路由加 prefill/decode 分离。这就是 PD 解耦的生产级落地样本。 来源：https://cio.eletsonline.com/artificial-intelligence/e2e-networks-blaze-ai-inference/76665/

壁仞天垓 300 自报部分场景超 H200（11/1–2）：国产推理芯片的媒体演示口径。第三方 INESA 外测只给了 1.05 倍，15% MoE 吞吐领先也是媒体转述。厂商自报，当路标看。 来源：https://www.siliconreport.com/iluvatar-corex-benchmarks-claim-tiangai-300-tops-nvidia-h200
