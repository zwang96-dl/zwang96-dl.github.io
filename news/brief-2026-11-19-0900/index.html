SGLang：1 条，新模型当天就接住了

#50186 是新模型支持。

Thinking Machines 刚开源了新模型。

名字叫 Inkling 2 Small。

594B 参数，每次只激活 17B。

混合专家就是多路专家分工。

上下文能到 100 万 token。

SGLang 发布当天就给了全套支持。

投机解码就是先让小模型打草稿。

投机解码、前缀缓存、HiCache 全都有。

NVFP4 和 MXFP8 两种量化权重都能跑。

两种都是低位浮点量化。

博客还给了实测数，见下面深读。

来源：https://github.com/sgl-project/sglang/pull/50186

vLLM：8 条，Rust 前端补了两块拼图

#68390 是 Rust 前端的活。

/v1/completions 现在能一次接一批提示词了。

以前批量传会直接报 400 错误。

Python 版早就能，Rust 版这回补上了。

#68612 也是 Rust 前端的活。

/generative_scoring 这个打分接口通了。

以前调它只会返回 501。

打分就是给几个候选项排个序。

#65018 跟 PD 拆分有关。

PD 拆分就是读题和生成分机器跑。

多模态渲染请求现在能只传元数据。

读题节点不用等整份张量传过来。

能少传不少东西，首字有望更快。

#68584 是 KV 搬运的观测修补。

KV 就是模型的草稿纸。

Mooncake 查租约这个操作以前会丢指标。

现在名字按字符串透传，不用改 Rust 代码。

#68717 是个编译修补。

Transformers 新版模型启动会报 KeyError。

修的是编译钩子找 self 的方式。

这也给 Transformers 5.24 升级扫了障碍。

#56617 是池化模型的修补。

Flash 打分取消时，缓存释放更稳了。

生产者停不下来最多等 10 秒。

#65251 是 AMD 的整理活。

MXFP4 是一种 4 位浮点量化。

MXFP4 线性算子换了个注册位置。

行为没变，只是归整代码。

#68652 是 AMD 的 CI 修补。

模型执行超时前先打印子进程堆栈。

方便定位卡住的地方。

来源：https://github.com/vllm-project/vllm/pull/68390

TRT-LLM：4 条，新卡跑 DeepSeek-V4.1

#22358 是新卡上的性能活。

DeepSeek-V4.1 跑在 Rubin 架构上。

Rubin 是英伟达新一代 GPU。

MXFP8 是一种 8 位浮点量化。

读题的矩阵乘换了专用算路。

稀疏注意力就是只算关键部分。

解码的稀疏注意力也接了自采样。

跟你评估的 PD 线直接相关。

#22513 是个小性能修补。

读题开 CUDA 图时，跳过没必要的引导解码活。

CUDA 图就是把一串操作预先打包好。

#22502 是新功能。

厂商锁现在能按作用域加了。

#22447 是发布流程的活。

C++ 许可证检查进了发布检查。

来源：https://github.com/NVIDIA/TensorRT-LLM/pull/22358

FlashInfer：2 条，解码核修了个崩溃

输入没对齐时，以前直接启动内核。

轻则报错，重则 CUDA 报错崩掉。

现在先拦下来，不合规矩的直接拒绝。

#9688 是 CI 的修补。

CUTLASS DSL 的路径从根目录解析。
