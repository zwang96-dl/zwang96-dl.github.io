腾讯 WeMM-Video：一个模型同时看视频、听声音、读文字

  • 作者：腾讯微信视觉团队，联合清华大学
  • 来源：arXiv 技术报告
  • 发布时间：2026-11-19 提交
  • 原文链接：https://arxiv.org/abs/2611.26409
  • 代码仓库：https://github.com/Tencent/WeMM-Video
  • 权重合集：https://huggingface.co/collections/tencent/wemm-video
  • 说明：数字全是腾讯自报，没有第三方实测

一句话

腾讯微信团队开源了 WeMM-Video。

一个模型同时处理视频、音频、图片和文字。

2B 到 35B 四个尺寸，Apache 2.0 协议。

35B 是开源视频理解的新高。

人话解读

以前的开源模型看视频只看画面。

听见了声音，也常常对不上画面。

WeMM 就是冲着边看边听来的。

它有四个尺寸：2B、4B、9B、35B-A3B。

前三个是稠密模型，35B 是 MoE。

MoE 就是专家混合，平时只用一部分。

35B 每 token 只激活 3B。

小尺寸的底座是 Qwen3.5。

35B 的底座是 Qwen3.6-35B-A3B。

音频编码器来自 Qwen2.5-Omni。

它有两种回答模式。

不思考模式直接回答，延迟低。

思考模式一步步推理，复杂任务更准。

思考还能减少看图说错话的幻觉。

训练用了约 1.2 万亿 token。

音画联合数据占了最大头，45.4%。

微信内部已经在用了。

直播电商、短剧分析、互动视频都在跑。

图 1：左上是看懂直播带货，右上是推理剧情。左下是听懂音乐变化，右下是读懂图表。一个模型四种活全包了。

核心方法

架构借鉴了 video-SALMONN 2 的设计。

视觉走底座原生的视觉编码器。

音频走一条专用通道。

Whisper 编码器先提声音特征。

采样率 16kHz，每 30 秒切一段。

Q-Former 再把特征压成 token。

Q-Former 就是压缩连续信号的小模块。

每 0.1 秒压成 1 个 token。

每秒音频变成 10 个 token。

视频帧和音频 token 按时间交错排列。

再贴上文字时间戳，帮模型对齐。

预训练分三个阶段走。

第一阶段只练音频对齐器。

其他部分冻住，先让模型听懂声音。

第二阶段放开全部参数，注入全模态知识。

第三阶段拉长上下文，练长视频和多视频。

后训练也是三个阶段。

多老师蒸馏补通用能力。

MrDPO 专治重复输出。

专家强化学习攻难任务。

关键数据

评测一共 120 多个。

35B 思考模式是开源视频理解新高。

17 个通用音画评测里，16 个超过 Seed2.0-Mini-0428。

同样 16 个超过 Qwen3.5-Omni-Flash。

离 Gemini-3.0-Flash 还有差距。

9B 思考模式超过 Qwen3-Omni-30B-A3B。

也超过了 MiniCPM-o-4.5-9B。

4B 同样超过了 30B 级的对手。

2B 在不少评测上打平 30B 级对手。

小模型越级，是这篇最值得注意的点。

训练数据约 1.2T token。

任务分布上，描述类占 37.7%。

知识问答占 17.5%，定位占 12.6%。

图 2：下面两路编码器，左边看画面，右边听声音。输出的 token 按时间顺序交错，排进大模型。时间戳 token 帮画面和声音对上号。

图 3：左图按模态分，音画联合数据占 45.4%。右图按任务分，描述类占 37.7%，是最大的一块。纯文本只有 2.6%。

部署方式

权重、代码、评测管线都开源了。

许可证是 Apache 2.0，随便商用。

部署要打补丁的 vLLM 或 SGLang。

原生引擎还不支持这种音画交错输入。

35B 官方例子用 2 卡张量并行。

张量并行就是把一层算力拆到多张卡。

另有 FP8、AWQ、GGUF、NVFP4 量化版。

2B 的 NVFP4 版只要 8GB 以上显存。

跟你的研究方向的关联

多模态 prefill 值得注意。

音频和视频 token 混排进序列。

KV 结构和显存占用跟纯文本不一样。

部署要打补丁，说明原生引擎有缺口。

补丁改了什么，可以对照着看。

小模型越级靠的是数据配比和后训练。

不是单纯堆参数，调参思路可以借鉴。

思考模式能降幻觉，但 token 更长。

解码成本更高，PD 拆分时值得单测。

术语表

  • 全模态：一个模型同时处理文字、图片、音频、视频
  • MoE：混合专家模型，每次只用一部分专家
  • Q-Former：把连续信号压成少量 token 的小模块
  • 思考模式：先一步步推理，再给出答案
  • OPD：在策略蒸馏，多位老师教一个学生
  • MrDPO：多轮直接偏好优化，专治重复输出
  • 张量并行：把一层算力拆到多张卡上跑
  • 音画联合数据：画面和声音成对出现的数据
