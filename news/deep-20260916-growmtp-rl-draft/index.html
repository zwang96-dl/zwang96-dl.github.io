GrowMTP：RL 训练里在线"长"出 draft 头，不用预训练草稿模型

原文：GrowMTP: Can RL Grow Its Own Draft Head?
作者：Minghua He 等（WeChat AI 腾讯 + 北京大学），2026-09-15 发布
链接：http://arxiv.org/abs/2609.16648v1
项目页：https://growmtp.github.io/

一句话人话版

  • RL 微调（强化学习后训练：让模型自己采样、再按好坏打分学）最烧钱的不是算法，是采样。
  • 模型一个 token 一个 token 往外蹦，rollout（采样阶段）占了大头。
  • 投机解码（speculative decoding：小模型先打草稿、大模型再批改的加速法）能救，但得先有个现成的草稿头。
  • 现成的草稿头很贵：EAGLE 给 70B 模型训一个约 5000 卡时。
  • DeepSeek-V3 的 MTP 头在预训练里烧了 148 亿 token。
  • GrowMTP 说：别预训练了，RL 训练的时候现学，学完直接加速本轮。

背景：RL 里学 draft 头是顺水推舟

  • RL 的 rollout 分布比预训练窄得多：模型翻来覆去就那几类回答。
  • 分布窄 = 草稿头好学，不用见过全世界。
  • RL 的验证步骤天然产出监督信号：每次"猜中/猜错"都是免费标签。
  • 分布对得上、标签管够，所以在线学是可行的。
  • 但直接套离线配方会翻车，论文列了三个坑。

三个坑：在线学 draft 头难在哪

  • 第一，验证信号只对"某次具体草稿"有效，换个草稿就没用了。
  • 第二，接受长度会变：学着学着草稿越来越准，训练目标跟着漂。
  • 第三，目标一旦拒绝，后面 token 的条件就变了：被拒的没进最终回答，拿它们训等于学"没发生的事"。

核心方法

总览：每个 RL 循环拆成两步

  • Rollout：正常做投机解码采样，顺手记三样东西。
  • 记的是：draft（草稿序列）、verification logits（验证时的 logits）、acceptance decisions（哪个位置被拒）。
  • Update：用记下来的东西训 draft 头，再正常更新策略主干。
  • 两边解耦：draft 头的梯度不回传主干（detach），主干该怎么学还怎么学。

组件一：Draft-Path Reconstruction（草稿路径重建）

  • 解决"训和用对不上"的问题。
  • 老配方用 teacher forcing（拿标准答案当每一步输入）。
  • 但上线时 draft 头吃的是自己的上一拍输出，输入分布根本不一样。
  • GrowMTP 用录下来的真实草稿路径重建 hidden state。
  • 训练吃的输入跟上线时一模一样，mismatch 就没了。
  • 只有第一个被拒的位置用 teacher forcing 补一下。
  • 被拒掉的 token 直接丢弃，不拿它们训。

组件二：detach 更新，跟主干互不干扰

  • draft 头只读主干最后一层的 hidden state。
  • 梯度不回传，主干完全感觉不到这个头的存在。
  • 好处：可以从随机初始化开局，零预热、零离线成本。
  • RL 目标函数原封不动，draft 头是个纯外挂。

组件三：DCA Loss（按接受链设计的损失）

  • 普通 CE/KL 是逐位置平均，没考虑"越深的位置越难被接受"。
  • DCA 直接建模接受链：只给第一个被拒位置之前的 token 梯度。
  • 消融显示：草稿越深（K 越大），DCA 对 CE/KL 的优势越大。
  • 直觉：别在"注定被拒"的位置上浪费梯度。

关键数据

  • Qwen3-4B（无原生 draft 头），500 步 RL：
  • 接受长度从 1.00 长到 2.91，从第 30 步起每步就比基线快。
  • rollout 加速 2.13 倍，端到端 1.60 倍（已含训头的开销）。
  • MiMo-7B-SFT（弱 draft 头）：rollout 1.93 倍，端到端 1.41 倍。
  • Qwen3.5-4B-Base（强 draft 头）：rollout 1.36 倍，端到端 1.20 倍。
  • 总账：整轮 502.8 卡时，比"离线训好头再 RL"（555.3 卡时）还省。
  • 没 draft 头的模型赚得最多：从零长出的头专治"裸奔"模型。

图注：(a) 接受长度从 1.00 爬到 2.91，随机初始化开局也能长出来。(b) 端到端单步耗时：灰线是无 draft 头的 AR 基线，青线是 GrowMTP，第 30 步（黄虚线）之后就一直更快，最终 rollout 快 2.13 倍、端到端快 1.60 倍。(c) 总算力账单：无头 803.9 卡时、离线训好头 555.3 卡时、GrowMTP 502.8 卡时——在线现学的比离线备好的还省。

跟你研究方向的关联

  • 投机解码是你推理优化工具箱的标配，这篇回答了"没草稿头怎么办"。
  • 如果你要在 SGLang 上给某个模型开投机解码，手里又没有现成 draft 模型，这套在线配方可以直接借鉴。
  • 注意边界：这篇加速的是 RL 训练时的 rollout，不是线上推理。
  • 但 draft 头的训练思想（detach、路径重建、DCA）跟推理侧训 draft 模型是同一套。
  • 跟 9/15 的 FastMTP 笔记对照看：FastMTP 是"有原生 MTP 头怎么调准"，GrowMTP 是"没有头怎么从零长出来"。

术语表

  • 投机解码 speculative decoding：小模型先猜几个 token，大模型一次性验，猜对就赚。
  • draft 头：负责"猜"的那个小模块，通常是个轻量 MTP 头。
  • MTP（multi-token prediction）：一次预测多个未来 token 的训练目标。
  • rollout：RL 里模型自己采样生成回答的阶段。
  • 接受长度 acceptance length：一次验证平均猜中几个 token。
  • teacher forcing：训练时拿标准答案当下一步输入的老办法。
  • detach：梯度不回传，draft 头的更新不影响主干。
  • GRPO：这篇用的 RL 算法，一组回答里比相对好坏。
