Foveated Compression：多模态视觉 token 压缩，学人眼看图

  • 论文：Foveated Compression: Selective High-Resolution Preservation for Token-Efficient VLMs
  • 作者：Donghyun Han, Jangho Park, Yuseok Bae（ETRI，韩国电子通信研究院；Kyung Hee University）
  • 发布：arXiv 2610.07729v1，2026-10-06（NeurIPS 2026 Workshop VLM4RWD）
  • 原文：https://arxiv.org/abs/2610.07729 ｜ PDF：https://arxiv.org/pdf/2610.07729

人话解读（一句话版本）

多模态模型最烧钱的是视觉 token。一张高清图进来，几千个 token 就没了。

这些 token 全堆在 prefill 阶段。首字延迟和显存，都被它们拖累。

以前的压缩很粗暴：要么整图缩小，要么直接裁一块。

这篇换了个问法：预算就这么多，高清分辨率该留给图片的哪块区域？

答案是学人眼。眼睛中央看得清、边缘模糊，这叫中央凹（fovea）。

整图先压成低清全覆盖，再挑最关键的一块恢复高清。全局不丢，细节也保住了。

核心方法

两步走，都在特征空间里做，不用重新编码图片。

第一步：Foveated Merger（压缩器），把 3×3 的原生 token 块压成 1 个。

  • 均值池化打底，加一个可学习的小残差头。
  • 训练方式叫行为自蒸馏：拿冻结模型的贪心输出当老师，压缩版学着模仿。
  • 参数只有 52.77M。视觉 backbone 和语言模型全程冻结，只训压缩器。

第二步：Foveated Selector（选择器），从 9 个格子里挑 1 格留高清。

  • 每个格子拼一个 512 维描述子：内容、压缩内容、压缩误差、位置。
  • 轻量到离谱：10.8M 参数，不用再跑一次语言模型。
  • 监督信号来自"穷举干预"：9 个格子挨个试，哪个得分最高就学哪个。
  • 选中的格子用原生 token 原地替换。token 总数精确锁定在 20.99%。

为什么要在特征空间做，不在像素层面。

像素层面下采样之后，高清信息就没了，找不回来。

特征空间压缩保留了原生 token 的"兼容性"。想恢复哪块，直接换回去就行。

不用再跑一遍视觉编码器，省一次前向。

图 1 人话解读。问题是"柜子左边的架子上有什麽"。原生分辨率：token 又多又贵。整图下采样：便宜但糊。token 压缩：便宜但局部细节全丢。直接裁剪：细节保住了但全局丢了。Foveated：整图低清全覆盖（全局不丢），再用 Selector 挑一格、Merger 恢复高清（局部细节回来），三项全绿。

关键数据

  • 11.11% token 预算下：均匀压缩跟直接下采样打平，统计上没显著差别。
  • 20.99% 预算下：学出来的选择器明显超过随机挑和固定挑。
  • 但整体仍不如直接把整图缩小。局部高清不是万能药。
  • 先知上限：上帝视角选格能到 82.73 分，学出来的只有 69.61。
  • 说明瓶颈在"选哪块"，不在"怎么压"。选择器还有很大提升空间。
  • 跨 37610 个样本：只用 11.11% token，86.1% 的题目答案保持不变。
  • 任务差异极大：POPE 上保留 94.3%，ChartQA 上只有 38.8%。
  • backbone 是 Qwen2.5-VL-7B-Instruct。评测集：GQA、MMBench、MME、POPE、OCRBench 等。

图 3 人话解读。(a) 不同任务对"高清"的依赖天差地别：ChartQA 只有 38.8% 的题目能在压缩后保持答对，POPE 高达 94.3%。(b) 78.5% 的样本随便选哪块都行，只有 21.5% 真正在乎选哪块。(c) 同样的 token 预算，上帝视角选格（82.7）比学出来的选择器（69.6）高出一大截——钱（token）没少花，是"花在哪"没选好。

跟你的研究方向的关联

  • 视觉 token 就是多模态 prefill 的大头。压 token 等于直接压首字延迟。
  • 这篇的方法插在视觉编码器后面、语言模型前面。
  • 跟 P/D 解耦里的 encoder 分离思路能对话：都是"视觉部分单独处理"。
  • 选择器"选哪块"的瓶颈，提示了一个方向：能不能用问题文本指导选择？
  • 论文自己也发现：压缩是否翻车，语言模型算完之后比选择器更容易看出来。
  • 换句话说，prefill 阶段的信息比预选择更准。
  • 这跟"encoder/prefill 资源分离"的权衡直接相关：分离得越早，信息越少。
  • 负责任的一面：作者没藏着掖着，局部高清不如全图缩小的结论写得很明白。

术语表

  • 视觉 token：图片被切成小块，每块变成一个向量。越多看得越细，也越烧钱。
  • prefill：模型先把输入全看一遍的阶段。视觉 token 全堆在这里。
  • 中央凹（fovea）：人眼视网膜中央看得最清的一小块区域。本文的灵感来源。
  • 行为自蒸馏：不用人工标注，让压缩版学着模仿原版模型的输出行为。
  • 穷举干预：9 个格子挨个试一遍，拿真实得分当监督信号。笨，但准。
  • 原生 token：未经压缩的视觉 token，保留了完整的细节信息。
