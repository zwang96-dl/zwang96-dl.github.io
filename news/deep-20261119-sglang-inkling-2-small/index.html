SGLang 首日支持 Inkling 2 Small：594B 开源模型当天就能跑

一句话

Thinking Machines 的 594B 模型刚出。

SGLang 当天就能跑了，还给了实测数。

人话解读

Inkling 2 Small 是第二代模型。

Thinking Machines 是 Mira Murati 创办的实验室。

模型是开源权重，Apache 2.0 协议。

594B 是总参数，每次只激活 17B。

混合专家就是多路专家分工。

每次只请几位专家干活。

上下文能到 100 万 token。

输入能看文字和图片，输出是文字。

定位是代理编码、视觉推理和知识工作。

首日支持的意思是：权重一放出，引擎当天就能跑。

不用等几周适配。

SGLang 覆盖了英伟达、AMD 和谷歌三家硬件。

两种量化权重都能跑。

NVFP4 是 4 位浮点量化。

MXFP8 是 8 位浮点量化。

NVFP4 那份至少要 500GB 显存。

MXFP8 那份至少要 800GB 显存。

换句话说，这不是单卡能玩的模型。

起步就是两张 B300，或者四张 H200。

对你来说，最值钱的是两点。

第一，SGLang 把这模型当成新标杆来测。

第二，测法里全是你评估里要的东西。

核心方法

MegaMoE：一个核包一层专家

DeepGEMM 是 SGLang 用的 MoE 矩阵乘库。

MegaMoE 把它扩展到 Inkling 2 Small。

一层里的 NVFP4 和 MXFP8 专家，一个核全包了。

以前要按格式分组调用。

现在一次调用走完一层。

效果直接体现在首字上。

首字就是第一个词出来的时间。

分组调用的老路子，首字慢 20% 到 27%。

DSpark 每步解码时间也降了 17%。

测的是批 64。

解码注意力核：单请求也能填满卡

模型用了混合注意力。

局部注意力和全局注意力混着用。

还加了 Block Attention Residuals。

这是一种跨层残差。

解码核是专门写的相对偏置核。

它把 KV 缓存切开，分到最多 64 个 CTA 上。

CTA 是 GPU 上的线程块组。

单请求也能把卡填满。

注意力每层从 25 微秒降到 9 微秒。

测的是批 1。

核融合：能合的都合了

注意力之前的所有操作，一个融合核走完。

路由的 sigmoid、偏置和 top-k，另一个核走完。

量化折进了专家矩阵乘里。

启动基本都用 PDL。

PDL 是程序化依赖启动，核与核之间不用回主机。

配套功能：投机解码和缓存全套

DSpark 是 SGLang 的投机解码。

投机解码就是先让小模型打草稿。

草稿头是模型自带的 MTP 头。

MTP 是多 token 预测。

统一 Radix 缓存管前缀缓存。

前缀缓存就是相同开头只算一次。

HiCache 管二级和三级缓存。

二级是主机内存，三级是 Mooncake 存的 KV。

MXFP8 的 KV 缓存只在 Blackwell 卡上开。

关键数据

解码吞吐的条件如下：

4 卡并行，TP4 加 EP4。

随机 8K 输入，1K 输出。

开着 DSpark 和 MegaMoE。

平台批 192 每卡解码吞吐批 192 每用户速度
VR2005895 词每秒123 词每秒
GB3003642 词每秒76 词每秒

批 1 时，GB300 每用户 441 词每秒。

每卡是 110 词每秒。

DSpark 接受率按每步 3.5 个 token 模拟。

注意这是模拟值，不是实测接受率。

硬件覆盖五家平台。

Blackwell 是 B300、GB300、B200、GB200。

Vera Rubin 是 VR200。

Hopper 是 H200。

AMD 是 MI350X、MI355X。

谷歌 TPU 是 v7x。

各有专用镜像。

厂商评测分（模型卡片，厂商自报）：

  • DeepSWE 72.1%。
  • Artificial Analysis Index 30.6 分。
  • BrowseComp 90.2%。
  • OmniDocBench 94.6%。

Miles 验证：DAPO-Math-17k 上 LoRA 微调。

8 张 GB300，93 步 GRPO。

GRPO 是一种强化学习算法。

奖励从 0.72 涨到约 0.85。

训练和采样 KL 散度约千分之 1.1 到 1.4。

多模态 Geometry3K 上 15 步，奖励从 0.50 涨到 0.94。

跟研究方向的关联

这篇跟多模态 P/D 评估直接对口。

第一，缓存三件套都能抄进评估清单。

前缀缓存、HiCache、MXFP8 KV 缓存。

读题节点开混合注意力前缀缓存。

HiCache 的 L2 和 L3 分层，正好对 PD 搬运。

第二，VR200 和 GB300 的数能当跨代基线。

同一模型、同一批大小，两代卡差 1.6 倍。

每卡解码吞吐 5895 对 3642。

评估里报跨代数时，可以拿这个当参照。

第三，DSpark 接受率 3.5 是个模拟值。

复现时要先测真接受率。

再报吞吐，别直接抄表里的数。

第四，显存门槛先算清楚。

NVFP4 要 500GB，MXFP8 要 800GB。

评估拓扑最少 4 卡起。

单卡 H100 跑不了这模型。

第五，Miles 的训练加采样同框验证值得学。

GRPO 采样就是推理。

KL 散度千分之一量级，说明采样和训练对齐了。

这招能抄进 RL 评估。

但数字均为作者自报。

只测了一个模型。

解码吞吐只报了 8K 输入、1K 输出一档。

首字只报了相对提升，没给绝对值。

术语表

  • MoE：混合专家模型，多路专家分工，每次只激活几位。
  • DSpark：SGLang 的投机解码，先让小模型打草稿。
  • MTP：多 token 预测，草稿头一次猜多个 token。
  • MegaMoE：DeepGEMM 的持久化 MoE 核，一层专家一次调用。
  • DeepGEMM：SGLang 用的 MoE 矩阵乘库。
  • HiCache：SGLang 的分层 KV 缓存，主机内存加 Mooncake。
  • Radix 缓存：SGLang 的前缀缓存，按前缀树共享。
  • MXFP8：8 位浮点量化，带缩放因子的低精度格式。
  • NVFP4：英伟达的 4 位浮点量化格式。
  • CTA：GPU 上的线程块组，协作线程阵列。
  • PDL：程序化依赖启动，核与核之间不用回主机。
  • GRPO：一种强化学习算法，组内比好坏再更新。
  • LoRA：低秩微调，只训一小部分参数。
  • KL 散度：两个分布差多远，越小越一致。
  • TP/EP：张量并行把权重切开，专家并行把专家分卡。
