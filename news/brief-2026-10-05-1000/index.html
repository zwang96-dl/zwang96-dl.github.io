  • 捞出两篇 10/2 的漏报，之前各期都没报过。
  • 智能体 RL 训练也有"解耦"大招：VenusRL。
  • 它的两个隐形税：慢轨迹拖住全局，沙盒内存只用了 8%。
  • 解法是"全解耦 + 优先级调度"。
  • 先用轻量预测器猜每条样本"还剩多长"。
  • 快做完的插队：抢 GPU 槽位、保 KV 前缀、跨 worker 搬家。
  • KV 缓存（草稿纸）淘汰时先踢闲置的，在跑的前缀死保。
  • 沙盒按页复用快照，写时才分开，密度拉满。
  • 数据：对 RollFlash 最高快 4.24 倍。
  • 环境成本最高降 89%。
  • 消融显示 KV 常驻是最大功臣，调度只排第三。
  • 这对你意味着：P/D 解耦评估里"保谁踢谁"的优先级思路可以直接抄。
  • 来源：arXiv 2610.03286
  • 长推理的 KV 缓存有新淘汰策略：AvoKV-E。
  • 老办法只看"这个 key 以后还读不读"。
  • 它发现两个盲点：低注意力的条目可能带着大 value 包。
  • 刚生成的条目可能还没被读过就被判了"死刑"。
  • 解法：先给新条目"观察期"。
  • 再按读取压力、key 冗余、value 分量打分。
  • 免训练，即插即用。
  • 数据：在最紧的缓存预算下涨幅最大，持平或超过现有基线。
  • 这对你意味着：长 CoT serving 的 KV 预算可以再压一压。
  • 来源：arXiv 2610.03007
