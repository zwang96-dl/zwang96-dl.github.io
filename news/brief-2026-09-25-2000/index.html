多模态大模型推理服务简报 · 2026-09-25（20点版）

晚上这轮窗口偏安静，框架六家都没动。 但捡回来两条昨晚到今天的干货，都对口。

访谈与深度

  • Latent Space 刚出了一期：OpenRouter 从种子到 Stripe。
  • 嘉宾是 OpenRouter 的 CEO Alex Atallah。
  • OpenRouter 是推理 API 网关的头部公司。
  • 一句话：它像模型超市的收银台。
  • 开发者调一个接口，就能切换几百个模型。
  • 现在每天经它手的 token 超过 10 万亿。
  • 这期聊了路由层怎么做成关键基础设施。
  • 还聊了 token 欺诈这个新话题。
  • 说白了：agent 自己调 API 刷 token，防不胜防。
  • 做推理网关和计费的人值得听一耳朵。
  • 链接：https://www.latent.space/p/openrouter
  • 一篇生产复盘：自动扩缩容掩盖了缓存崩盘。
  • 故事很简单：RAG 切块从 512 改成 500 个 token。
  • 结果前缀缓存命中率从 85% 掉到 4%。
  • 前缀缓存就是存重复提示词的草稿纸，省得每次重算。
  • 流量没涨，GPU 副本却多了 80%。
  • 凶手是哈希链：vLLM 的 KV 缓存按 16 个 token 一块存。
  • 每块的哈希都带着前一块的哈希，像串起来的锁链。
  • 第 500 个 token 一变，后面整串全对不上。
  • 等于整条作废，全得重算。
  • SGLang 的 RadixAttention（树形前缀缓存）也一样。
  • 前缀一分叉，整枝缓存就掉光了。
  • 更扎心的是自动扩缩容：它只看队列长度。
  • 队列变长就加机器，延迟达标了，账单却翻倍。
  • 作者给了三组 PromQL，直接监控缓存命中率。
  • 还能算出每千请求烧了多少 GPU 秒。
  • 还有个数据点：llm-d 的前缀感知路由很猛。
  • TTFT p90 从 135.5 秒压到 0.3 秒内，吞吐 2.1 倍。
  • 说白了：请求得送到存着它前缀的那台机器上。
  • 链接：https://podostack.com/p/autoscaler-hid-prefix-cache-regression
